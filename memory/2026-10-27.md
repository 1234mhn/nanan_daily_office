**2. 🔴 我犯的错（用户当场纠正，重要教训）**

- **真相**：原文 Fig.2 图注是按**处理对象**组织的，不是按 Fig.1 的问题编号。GPT-IE 治「多病+反复出现」并保留位置程度；IKI 治「没见过的类」；SSM 治「标签太粗太硬」。SSM 和 GPT-IE 是**流水线上下游**关系，不是并列各治一个毛病。

**3. 四个问题在分类领域的定位（用户问「是不是分类里常见问题」）**
- 1a 多病混淆 → 🔵 医学+多模态特有（一段文本描述多个对象）
- 1b 假阴性 → 🟢 通用（类内差异 / false negative）
- 2a 丢子类 → 🟢 通用（层次分类 / 标签粒度），但要看标签体系
- 2b 认不出新病 → 🟢 通用 open-set，医学后果更严重
- **判断**：这篇能占住位置靠 1a + 1b，2a/2b 是顺带追加的

**4. 为什么是三元组不是四元组**
- 临床够用：一个病灶「是什么/在哪/多重」= 决策最小信息集
- 不和 IKI 重复：形态归 IKI 的视觉描述
- 工程可控：字段越少 LLM 抽得越准、SSM 相似度越干净
- **严格说不是三个平等字段，而是「1 个主键（category）+ 2 个可选属性」**
- 缺 severity/location 保留，缺 category 删除（原文明确）
- **可挑战的三个点**：尺寸/数量信息丢失、形态被推给静态 Dict、多灶性（multiple lesions）无法表达

**5. 三个模块工作原理（详细讲过）**
- **GPT-IE**：`{severity, location, category} = f_IE(report + prompt)`，GPT-3.5-Turbo，1对1 → 1对多
- **IKI**：`T_e = Dict(T_f[categories])`，病名 → 视觉描述。类比「不让模型分辨肺炎和气胸两个词，而是分辨两段描述出来的图」
- **SSM**：M×M 文本相似度 → 逐列取 max → N×M 标签矩阵 s；损失 `L = MSE + CE`

**6. 🔴 SSM 取 max 的关键澄清（用户反复问）**
- 原文：「the maximum values of **each column** in a sub-matrix of size `cᵢ × M`」
- `cᵢ` 是行数，`M` 是列数
- **横向看是压行（cᵢ 行 → 1 行），纵向看是每列取最大 —— 同一件事**
- 不用 mean 的原因：避免弱匹配污染 + 防止强匹配被削弱

**7. 传统 vs SSM 的假阴性问题（用户追问「标签是0，不应该分为一类吗」）**
- 用户直觉正确，我就是顺着这个讲清的
- 关键：传统对比学习只认「是不是同一条记录」，不读文本内容，所以不知道两份报告写同一个病
- 用「两个同班同学但互不认识，学校只允许认识的结对」的比喻讲通了
- 用户后面要求「通俗易懂，不要每次说那么多」→ **后续讲解明显收短，成功**

**8. 用户问「传统是二分类吗，SSM 说相似度」**
- 校准：传统是**硬标签**（配对/不配对的二分类排序），SSM 是**软标签**（0~1 相似度回归）
- 推荐用行业标准说法「硬标签 → 软标签」
- 补充：MedKLIP 那一派其实是**三分类** present/uncertain/absent

**9. 先验知识 ≠ Dict（用户问「引入先验知识，是 dict 吗」）**
- **Dict 是载体（抽屉），先验知识是内容（抽屉里的东西）**

**新版第 2 页要点（已定稿可直读）**：

> 这条路子确实有效。**ConVIRT** 开了头，**GloRIA** 加了局部对齐，**MedCLIP** 用语义匹配处理假阴性，**MedKLIP** 抽病名加模板，一层层往前推。
