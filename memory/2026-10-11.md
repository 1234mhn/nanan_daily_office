## 过程（踩坑记录）
1. **Claude Code 起不来 → API 余额不足**：lmuai.ai 账户 $-0.11 欠费（403）。用户充值后恢复。
2. **COS 权限反复被重置**：/root/.openclaw 是 700，被某进程反复重置回 700，www-data 读不到 cos_node.mjs。
   → **解决**：把 tencent-cos-skill 整个复制到 `/www/korean_course/_cos_tools_full/`（www-data 属主），并生成 `.env` 凭证。以后 COS 操作直接用这个路径。
3. **大文件上传卡死**：cos_node.mjs 的 `upload`（putObject 流式）在公网传输时卡住（send buffer 堆 600KB 不动）。
   → **解决**：用 `upload_slice.mjs`（sliceUploadFile 分片 2MB + 重试），稳。已复制到 `_cos_tools_full/scripts/upload_slice.mjs`。
4. **4K HDR→SDR 转码慢**：2 核机器，0.057x 速度，三段 ~40 分钟。一次签名URL一条 ffmpeg 连截三段（省流量）。
