### 五、关键教训（下次必看）
1. **Unicode 下标字符（ᵢ ₖ ⱼ）不可靠**：Word/LO 字体缺字形，渲染错乱。必须用 OMML 或 run.subscript
2. **Cambria Math 不能设 eastAsia 为中文字体**：会导致中文段落被拆行错乱（本次踩过，段23 曾整段散架）
3. **说明段里的变量**（如"其中 L_align 为…"）：用 Times New Roman + italic + subscript 最稳，不要用 Cambria Math
4. **公式编号换行问题**：`tab + oMath + tab + (n)` 在 LibreOffice/Word 下 tab 常失效 → 改用无框表格才稳
5. **图内文字验证方法**：pytesseract `image_to_data` 算 bbox 重叠率，>45% 判为重叠；图片边缘 6px 内查深色像素判溢出
6. **视觉模型不可用时的替代方案**：`image` 工具报 401（anthropic key 失效），`read` 读图也不支持 → 只能靠 OCR + 像素分析间接验证
7. **python-docx 插图**：清旧图要按 `pic:pic` / `a:blip` 找 run 删除；删完可能残留空段落，需再删对应 rId 的段
