## 第6课 · 自我介绍 要点（自存）
- 이름이 뭐예요? / 고향이 어디예요? / 이게 뭐예요? → 이/가 主语标记
- 주호진입니다 → 명사 + 입니다（最正式断定），口语 -이에요/예요
- 반가워요（반갑다 ㅂ不规则）/ 나는 차무희예요
- 압니다 ← 알다，ㄹ 在 ㄴ 前脱落（必背不规则）
- 人名 + 씨 礼貌称呼，男女通用
- 音变：이름이 [이르미]、입니다 [임니다]、희→히

## 第14课 · 拍摄现场散步 要点（自存）
- -기 名词化（기다리기）、-는데요 委婉说明/期待回应
- -(으)ㄹ 줄 몰랐다 / 알았다（出乎意料 vs 原以为）
- -나/이나 选择、「더 + 形容词」比较级
- -아/어도 让步（即使…也）
- 音变：지루했죠 [지루해쬬]、재미있던데요 [재미읻떤데요]、괜찮아요 [괜차나요]、이렇게 [이러케]

## 第38课 · 初次见面 要点（自存）
- 컨디션（英 condition）어때요? / 컨디션이 좋아요
- 좋아요 [조아요] ㅎ脱落
- 웬만하면 + -(으)ㄹ 거고、-ㄹ 거예요 将来
- 눈에 띄다 → 눈에 안 띄게（-게 副词化）
- 长句：카메라는 웬만하면 눈에 안 띄게 찍을 거고…（紧音化 찍을 거고 [찌글꺼고]）
