- 现象：派 Claude Code 重做韩语第9课，报错 `403 余额不足 -0.5 元`，任务直接停摆。
- 根因：调用 AI 的 API 账户欠费（≤0），AI 拒绝干活。
- 教训：前一天反复调用 AI 烧约50元但未落成完整成果，浪费在"反复试错+未完成"循环。
- 改动方案：①用 AI 前先查余额；②素材齐全时优先手动做，不盲目烧 AI；③大任务先想清全流程。
