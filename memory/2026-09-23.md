**🔥 核心发现：结构性转移 C\* ≈ 2.15×10²⁰ FLOPs**

- C < 2×10²⁰：**质量提升开销主导**（10¹⁸ 时高达 98.3%）
- C > 2×10²⁰：**基础训练开销主导**（10²⁴ 时达 77.9%）
- **D*/N* ≡ 20.00 恒定**（跨 7 个量级）→ 转移的不是规模增速，是**钱的花法**

**M4 活跃约束集合跃迁法（用户点出，新增）：**

定义：A(C) = (预算约束是否紧, 主导成本成分, 占比>50%的成分集合)

| 事件 | log₁₀C | 预算 |
|:--|:--|:--|

M1 与 M4 **精确互相印证**（同为 logC=20.33）；43 个点平均预算利用率 **0.9610**（最优解几乎贴预算边界）。

**KKT 分析（Q*=1 的真相）：**
```
∂L/∂Q = −C·δ·(1−Q)^(δ−1)，δ=0.99052 < 1
→ Q→1 时 (1−Q)^(δ−1) → +∞，边际收益发散
∂C/∂Q = D·g'(Q) 有限
→ KKT 在 Q<1 处无解 → Q*→1（真最优，非求解器缺陷）
```
⚠️ 陷阱说"各档 Q*=1 质量拉满"是错的——错不在数字，在于**不给解释、不做现实约束**。
正确做法：证明机理 + 引入 Q_max 敏感性分析（Q_max 1.0→0.7，Loss 上升 ~7%）。
