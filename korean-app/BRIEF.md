# 韩语单词学习 Web 应用 — 阶段一：首页

## 项目定位
个人自用的韩语单词学习应用（用户是韩语老师）。可爱卡通软萌风。
本次只做【首页 = 闯关选择页】。后续会追加：闯关答题页、词典页、AI 对话页。
架构必须为后续页面留好路由和组件扩展口子。

## 技术栈（严格遵守）
- Next.js（App Router）+ TypeScript
- TailwindCSS
- shadcn/ui（需要的组件自行 init/add）
- 静态导出：next.config 里 output: 'export'
- 部署基线路径：basePath '/korean-app'，assetPrefix 同（因为会部署到 https://nannan2026.cn/korean-app/）
- 数据层：localStorage（做一个 lib/storage.ts 统一封装，留好将来换 API 的接口）

## 视觉风格（重点，务必做到位）
- 可爱卡通软萌，治愈轻松
- 圆角大（rounded-3xl / rounded-[2rem] 级别）
- 柔和马卡龙配色，低饱和度，不要鲜艳高饱和
- 不要尖锐线条，不要冷硬边框
- 圆润卡通插画元素（用 emoji 或纯 CSS/SVG 画，不引外部图片）
- 浅色模式为主，保证浅色模式下配色舒服
- 留白充足，居中布局

## 首页功能需求
1. 页面标题：韩语单词大冒险
2. 闯关模块：卡片网格，每个卡片 = 一个关卡
   - 显示：关卡序号、关卡名称（例：第1关 基础名词 / 第2关 常用动词）
   - 完成进度条
   - 星星评价（3 颗星）
3. 关卡三种状态：
   - 已通关：彩色卡通卡片，星星点亮
   - 当前可解锁：高亮 + 明显的「开始闯关」按钮
   - 未解锁：灰色置灰 + 锁图标，不可点
4. 顶部信息栏：卡通头像 + 累计学习单词数 + 总获得星星数
5. 底部两个跳转按钮：【单词词典】【AI 对话答疑】
   - 分别跳 /dictionary 和 /chat（这两页本期先建占位页，保证路由能跳）
6. 交互：
   - 鼠标 hover 卡片轻微上浮动画
   - 按钮点击柔和反馈（scale 微缩或 ripple 感）
7. 布局：居中、留白足、移动端适配良好

## 数据
先用假数据建 6 个关卡示例（第1关 基础名词 ... 第6关 ...），
至少包含：1个已通关、1个当前解锁、其余未解锁。数据放 lib/levels.ts 统一管理。
