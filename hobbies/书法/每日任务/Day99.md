## 🏋️ 控笔训练（5min）

**① 一波三折线 × 15条**
- 轻入 → 渐按 → 最重 → 平出
- 结尾停半秒再出锋，**尾端平行米字格横向平出，严禁上翘**

**② 三点水弧线 × 10组**
- 点、点、提三点连成一条微弧，节奏 **紧 → 紧 → 松**

**③ 竖折短竖定位 × 10组**
- 竖只占整体高度约 1/3，转折处往回带 0.5mm

**④ 圆圈 × 3行**
- 匀速画圆，手腕不抖

## 🖌️ 笔画/例字

### 捺（斜捺/平捺）× 20遍

```
轻入 → 渐按 → 最重 → 平出
```

**🔑 收笔放慢，锋尖与米字格横线齐平，别急着甩。**

### 三点水（氵）× 15遍

```
点（偏左）→ 点（偏左）→ 提（向右下弧出）
```

**🔑 前两点贴得近、走同一个方向，第三点打开才是弧。**

### 竖折 × 15遍

- 竖短、折角干脆、横部才舒展
- 空手在空中走 2~3 遍轨迹再落纸

### 例字 × 各5遍

「之」「送」— 捺尾平出
「河」「池」— 三点水成弧，竖弯钩横段拉开
「世」— 竖折竖部收短，出头够
「冶」「冷」— 底部「口」写扁；二点水拉开 1.5~2 倍点宽
