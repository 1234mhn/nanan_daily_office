## 🏋️ 控笔训练（5min）

**① 一波三折线 × 15条**
- 轻入 → 渐按 → 最重 → 平出
- 结尾停半秒再出锋，**锋尖平行米字格平出，不上翘**

**② 三点水弧线 × 10组**
- 点、点、提连成一条微弧，节奏 **紧 → 紧 → 松**

**③ 言字旁点位控笔 × 10组**
- 点偏右、横微斜上提，横折提一气连贯

**④ 圆圈 × 3行**
- 匀速画圆，手腕不抖

## 🖌️ 笔画/例字

### 捺（斜捺/平捺）× 20遍

```
轻入 → 渐按 → 最重 → 平出
```

**🔑 收笔放慢，锋尖与米字格横线齐平，别急着甩。**

### 三点水（氵）× 15遍

```
点（偏左）→ 点（偏左贴弧）→ 提（弧出）
```

**🔑 前两点贴得近、走同一个方向，第三点打开才是弧，别排成三根棍。**

### 言字旁（讠）× 15遍

- 点一定偏右，横微斜上提
- 横折提转折利落，提锋向右上

### 例字 × 各5遍

「之」「送」— 捺尾平出
「江」「河」— 三点水成弧，前紧后松
「说」「话」— 言字旁点靠右、横倾斜
「冶」「冷」— 底部「口」写扁；二点水拉开 1.5~2 倍点宽
「世」— 竖折竖部只占 1/3 高
