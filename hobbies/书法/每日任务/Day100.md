# 🖌️ 书法练习 · 第100天

> 🎉 满百天了！从6月16日第一天手抖着写横，到今天，这是第100次落笔。今天不追新，只把练过的东西串成一件漂亮的事。

---

## 🏋️ 控笔训练（5min）

**① 一波三折线 × 15条**
- 轻入 → 渐按 → 最重 → 平出
- 尾端平行米字格横向平出，**严禁上翘**

**② 三点水弧线 × 10组**
- 点、点、提连成微弧，节奏 **紧 → 紧 → 松**

**③ 圆圈 × 3行 + 竖折短竖定位 × 10组**
- 画圆匀速不抖；竖折的竖只占整体高度 1/3

---

## 🖌️ 笔画/例字

### 捺 × 20遍（收官重点）

```
轻入 → 渐按 → 最重 → 平出
```

**🔑 收笔放慢，锋尖与米字格横线齐平。**

### 三点水（氵）× 15遍

```
点（偏左）→ 点（偏左）→ 提（向右下弧出）
```

**🔑 前两点贴近同向，第三点打开成弧。**

### 竖折 × 15遍

- 竖短、折角干脆、横部舒展
- 空手在空中走 2~3 遍轨迹再落纸

### 例字 × 各5遍

「之」「送」— 捺尾平出
「河」「池」— 三点水成弧，竖弯钩横段拉开
「世」— 竖折竖部收短，出头够
「冶」「冷」— 底部「口」写扁；两点水拉开 1.5~2 倍点宽

### 🎁 百天纪念作品（10min）

选最喜欢的一句，用今天练的字完整写一遍，落款写日期。
不限长短，但要**一次写成、不改笔**——就当交给自己的一份百天答卷。

## 💡 要点提醒

1. **⚠️ 捺尾平出** — 老问题头号，每个捺停半秒检查
2. **⚠️ 三点水前两点别平行排队** — 贴弧走，第三点打开
3. **⚠️ 竖折竖部别再拉长** — 「世」字竖只占 1/3 高
4. **底部「口」写扁不写方** — 「冶」字笨重的根源
5. **起笔像羽毛碰纸** — 别砸
6. **写作品时先看帖3秒** — 默念结构比例再落笔
