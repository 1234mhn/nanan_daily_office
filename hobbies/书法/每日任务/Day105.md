## 🏋️ 控笔训练（5min）

**① 一波三折线 × 15条**
- 轻入 → 渐按 → 最重 → 平出
- **锋尖平行米字格平出，不上翘**

**② 三点水弧线 × 10组**
- 点、点、提走一条微弧，节奏 **紧 → 紧 → 松**

**③ 尖横转提 × 10组**
- 短横后接提锋，模拟言字旁横折提，转折不拖沓

**④ 扁口框 + 竖折控笔 × 各10个**
- 口框扁宽不方；竖折竖部只占 1/3 高，底部微绕再转向

## 🖌️ 笔画/例字

### 捺（斜捺/平捺）× 20遍

```
轻入 → 渐按 → 最重 → 平出
```

**🔑 收笔停半秒再出锋，收在线外面就重来。**

### 言字旁（讠）× 15遍

- 点偏右、横微斜上提
- 横折提转折干脆，提锋向右上

### 三点水（氵）× 10遍 · 两点水（冫）× 10遍

```
冫：点靠上，间距拉开 1.5~2 倍点宽
氵：前两点贴弧走同一方向，第三点打开
```

### 例字 × 各5遍

「之」「送」— 捺尾平出
「说」「话」— 言字旁点靠右、横倾斜
「江」「海」— 三点水成弧
「冷」「冰」— 两点水拉开间距
「冶」— 底部「口」写扁
「世」— 竖折竖部只占 1/3 高

### 整句检验 × 3遍

「之江冷世，说话送海」

**🔑 不描不改，一次写到底，看六字里哪个最不像。**
