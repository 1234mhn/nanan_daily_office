## 🏋️ 控笔训练（5min）

**① 三点水弧线 × 10组**
- 先画一条淡弧，三个点贴着弧走
- 节奏 **紧 → 紧 → 松**，第三点打开

**② 二点水 × 10组**
- 上下两点间距拉到 **1.5~2 倍点宽**
- 宁散勿挤

**③ 一波三折线 × 10条**
- 轻→按→提，心里数「1-2-3」
- 尾端**平行米字格横向平出**

**④ 横线 × 10根**
- 左低右高5°，眼盯终点下落笔，别飘

## 🖌️ 笔画/例字

### 三点水（氵）× 15遍

```
① 上点：轻顿，偏右
② 中点：略下、略外
③ 下点：上扬挑出，打开
```

**🔑 一条弧，不是三根竖排队。**

### 捺（斜捺/平捺）× 20遍

```
轻入 → 渐按 → 最重 → 平出
```

**🔑 收笔放慢，锋尖平行米字格，严禁上翘。**

### 言字旁（讠）× 10遍

- 点**偏右**，横**微斜上提**，横折提折角干脆

### 二点水（冫）× 10遍

- 两点拉开，下点略大，整体靠上

### 例字 × 各5遍

「江」「河」— 三点成弧
「之」「送」— 捺尾平出
「说」「请」— 言字旁归位
「冶」「冷」— 底部「口」写扁；二点水拉开

## 💡 要点提醒

1. **⚠️ 今日重点：三点水成弧 + 捺尾平出** — 这两项反复出现，写到就停下来查一眼

4. **「冶」类底部口** — 扁宽，不写方
5. **起笔别砸** — 老毛病，像羽毛碰纸
