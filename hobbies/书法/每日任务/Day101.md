## 🏋️ 控笔训练（5min）

**① 一波三折线 × 15条**
- 轻入 → 渐按 → 最重 → 平出
- 尾端与米字格横线齐平，**严禁上翘**

**② 三点水弧线 × 10组**
- 点、点、提连成微弧，节奏 **紧 → 紧 → 松**

**③ 起笔轻触 × 20个 + 圆圈 × 3行**
- 起笔像羽毛碰纸，不砸；画圆匀速不抖

---

## 🖌️ 笔画/例字

### 捺（斜捺/平捺）× 20遍

```
轻入 → 渐按 → 最重 → 平出
```

**🔑 收笔放慢半拍，锋尖平行米字格横线。**

### 三点水（氵）× 15遍

```
点（偏左）→ 点（偏左）→ 提（向右下弧出）
```

**🔑 前两点贴弧走，第三点打开，不要三根棍平行排队。**

### 竖折 × 15遍

- 竖只占整体高度 1/3，折角干脆，横部舒展
- 落笔前空手走 2~3 遍轨迹

### 例字 × 各5遍

「之」「送」— 捺尾平出
「河」「池」— 三点水成弧；竖弯钩横段拉开
「世」— 竖折竖部收短
「冶」「冷」— 底部「口」写扁；两点水间距拉至 1.5~2 倍点宽

### 成篇小练（10min）

任选一句喜欢的四字或七字句，用今天练的字写一遍，落款日期。
**一次写成不改笔**，重点看字距是否均匀、大小是否一致。

## 💡 要点提醒

1. **⚠️ 捺尾平出** — 头号老问题，每个捺停半秒自检
2. **⚠️ 三点水别平行** — 贴弧走，第三点打开
3. **⚠️ 竖折竖部别拉长** — 「世」字竖只占 1/3
4. **底部「口」写扁不写方** — 「冶」字笨重的根源
5. **起笔像羽毛碰纸** — 别砸
6. **每个字先看帖 3 秒** — 默念结构比例再落笔
