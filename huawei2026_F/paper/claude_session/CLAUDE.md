# F题论文写作项目

## 目标
按官方模板格式，把 F 题（数据质量评价 / 广义标度律 / 算力优化）写成完整 Word 论文。

## 官方格式规范（严格遵循）
- 页面 A4，上下边距 2.54cm，左右 3.17cm
- 正文：宋体小四（12pt），1.5 倍行距，两端对齐，首行缩进 2 字符
- 一级标题「一、XXX」：三号（16pt）黑体居中
- 二级标题「1.1 XXX」：四号（14pt）黑体左对齐
- 三级标题「5.1.1 XXX」：11pt 黑体左对齐
- 封面：Logo提示 → 22pt 三行标题 → 18pt 两行标题 → 题目14pt → 信息表
- 摘要：16pt 标题 + 12pt 正文（四段式：问题一/二/三/综上）
- 目录：16pt 居中 + 点线页码
- 页码：封面无，摘要起页脚居中从 1 连续
- 无页眉；不得有暴露身份的标记
- 表格：有边框，表头居中加粗，正文 10.5pt
- 图片：居中，图题在图下方

## 论文结构
封面 → 摘要 → 目录 → 一、问题重述 → 二、问题分析 → 三、模型假设与符号说明
→ 四、数据预处理 → 五、模型建立与求解（5.1/5.2/5.3，各含 .1求解思路/.2模型建立/.3求解与分析）
→ 六、模型分析检验 → 七、模型评价与推广 → 参考文献 → 附录

## 铁律
1. 所有数值来自源文档，禁止编造
2. 单个完整 Word 文档，不拆分
3. 用 python-docx 生成
4. 输出到 ./docx/F题_论文.docx
