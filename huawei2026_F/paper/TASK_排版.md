## 官方模板精确规格（从 源_论文模板.docx XML 提取，**必须逐条执行**）
- 页面：A4，上下边距 **2.54cm**，左右 **3.18cm**
- 正文行距 **1.5 倍**
- Normal 样式：西文 Times New Roman，东亚 **宋体**，字号 **12pt（小四）**
- 封面结构（自然流，不强制分页）：
  1. 空段 ×2
  2. Logo 提示行（居中）：`【此处放置四个 Logo：CPIPC / 中国研究生创新实践系列大赛 / HUAWEI / 校徽】`
  3. 空段 ×2
  4. 三行大标题 **22pt 加粗居中**：`中国研究生创新实践系列大赛` / `“华为杯”第二十三届中国研究生` / `数学建模竞赛`
  5. 空段 ×8
  6. 两行标题 **18pt 加粗居中**：`“华为杯”第二十三届中国研究生` / `数学建模竞赛`
  7. 空段 ×1
  8. 题目行（居中）：`题　目：` 加粗 14pt + 题目内容 14pt
  9. 空段 ×1
- 摘要（紧跟封面，同一连续流，**不加分页符**）：
  1. `摘　要：` **16pt 加粗居中**
  2. 摘要正文：12pt，**两端对齐**，**首行缩进 24pt（2字符）**
  3. `关键词：` 加粗 12pt + 关键词（全角空格分隔）
- **分页符** → 目录
- 目录：`目　录` **16pt 加粗居中**；条目 12pt，**右对齐制表位 + 点线引导符**指向页码（制表位位置约 14.6cm）
- **分页符** → 正文
- 标题层级：H1 **16pt 加粗居中** / H2 **14pt 加粗** / H3 **11pt 加粗**
- 表格：`Table Grid` 有边框，表头加粗居中，正文 **10.5pt**，表格整体居中
- 图：居中，图题在图**下方**居中（10.5pt）
- **无页眉**；页码从摘要页起，页脚居中，阿拉伯数字从 1 连续编号
- **不得有任何暴露答题人身份的标记**
