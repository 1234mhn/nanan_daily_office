# 二、每句 6 件套（📍单词 → 💬短语 → 💬句型/接口 → 例句1/2 → 🎵音变现象）

## 1. 형은? / 어, 호진아 ┃ 哥呢？ / 哦，浩镇 ┃ Where is he? / Hey, Ho-jin.
- 📍**单词**：형 = 哥（男生对年长男性）｜호진 = 浩镇（人名）｜아 = 喂/哎（叫熟人，接名字后）
- 💬**短语**：형은? = 哥呢？（问"哥在哪"）；语气随性
- 💬**句型/接口**：名词 + 은/는？→ "……呢？"；有收音+은，无收音+는
  - 例句1：엄마는?（妈呢？）
  - 例句2：지선이는?（智善呢？）
- 🎵**音变现象**：호진아 → 连读顺畅，无特殊变化；"아"轻声

## 2. 형, 일어나, 형, 어? ┃ 哥，起来吧，哥 ┃ Hey, get up. Come on, get up.
- 📍**单词**：형 = 哥｜일어나다 = 起来/起身｜어 = 啊/喂（催促语气）
- 💬**短语**：일어나 = 起来（命令/劝诱形）；反复呼喊 형 表急切
- 💬**句型/接口**：动词词干 + 아/어（口语命令）= "……吧"
  - 例句1：앉아.（坐吧。）
  - 例句2：먹어.（吃吧。）
- 🎵**音变现象**：일어나 → 收音 ㄹ 弱化，连读顺滑，接近 [이러나]

## 3. 어, 호진아 ┃ 哦，浩镇 ┃ Hey, Ho-jin.
- 📍**单词**：어 = 哦/嗯（应答、恍然）｜호진 = 浩镇｜아 = 呼唤词
- 💬**短语**：어 + 人名 + 아 = "哦，某某"（认出来）
- 💬**句型/接口**：名字有收音 + 아，无收音 + 야；호진 有收音 ㄴ → 호진아（亲昵呼唤）
  - 例句1：민수야.（民秀呀。）
  - 例句2：철수야.（哲秀呀。）
- 🎵**音变现象**：호진아 → [호지나] 连读（ㄴ + 아）

## 4. 왜 창피하게 밖에서 울고 있어? ┃ 干吗在外面哭，不丢脸吗？ ┃ Why are you crying in public? You're embarrassing yourself.
- 📍**单词**：왜 = 为什么/干吗｜창피하다 = 丢脸/羞耻｜밖 = 外面｜-에서 = 在……（地点）｜울다 = 哭
- 💬**短语**：창피하게 = 丢人地（副词形，反问语气）
- 💬**句型/接口**：왜 + 副词形 + 动词现在时？→ "干吗……（反问/责怪）"
  - 例句1：왜 여기서 자고 있어?（干吗在这儿睡？）
  - 例句2：왜 그렇게 말해?（干吗那么说？）
- 🎵**音变现象**：밖에서 → [바께서]（ㄱ 紧音化）；창피하게 → 连读顺滑

## 5. 일어나, 가자, 자 ┃ 起来吧，我们走 ┃ Let's go.
- 📍**单词**：가다 = 去/走｜자 = 来/走（语助词，催促、引路）
- 💬**短语**：가자 = 走吧（劝诱形）；자 重复催促
- 💬**句型/接口**：动词词干 + 자 = "……吧（咱们）"
  - 例句1：먹자.（吃吧。）
  - 例句2：집에 가자.（回家吧。）
- 🎵**音变现象**：无特殊变化；"자"短促轻读

## 6. 야, 신지선이 무슨 내가 먼저 헤어지자 그랬대 ┃ 喂，申智善说是我先提的分手 ┃ Guess what? Shin Ji-sun said I broke up with her first.
- 📍**单词**：야 = 喂（叫熟人）｜신지선 = 申智善（人名）｜무슨 = 什么/怎么（表不解、反驳）｜먼저 = 先｜헤어지다 = 分手｜-대 = （转述）说……
- 💬**短语**：헤어지자 그랬대 = 说（我）提了分手（转述+引述）
- 💬**句型/接口**：动词 + 자고 하다 → "说要……"；-대 = -다고 해（听说/转述）
  - 例句1：내가 먼저 가자고 했대.（说是我先说要走的。）
  - 例句2：그 사람이 사랑한대.（他说他爱。）
- 🎵**音变现象**：그랬대 → [그랬때]（ㄷ 紧音化）；헤어지자 → 连读

## 7. 나는 진짜 그런 적이 없는데 ┃ 我真的没有那样过啊 ┃ But I never did.
- 📍**单词**：진짜 = 真的｜그런 = 那样的｜적 = 时候/次数（表经历）｜-없다 = 没有
- 💬**短语**：그런 적이 없다 = 从没那样过（经历否定）
- 💬**句型/接口**：动词过去 + ㄴ/은 적이 없다 = "从没……过"
  - 例句1：거짓말한 적이 없어요.（从没撒过谎。）
  - 例句2：본 적이 없어요.（从没见过。）
- 🎵**音变现象**：없는데 → [업는데]（ㅄ 收音简化）；적으로 连读

## 8. 나보고 잘 생각해 보라고 하는데 난 진짜 그런 적이 없거든? ┃ 她让我好好想想，可我真没那样过啊 ┃ She told me to think carefully, but I swear I never did.
- 📍**单词**：나보고 = 对我（说）/让我｜생각하다 = 想｜-라고 하다 = 说（让）……｜-거든 = 表强调理由/提醒
- 💬**短语**：생각해 보라고 하다 = 让我好好想想
- 💬**句型/接口**：动词 + (으)라고 하다 → "让（某人）做……"；句尾 -거든 = "……嘛/你不知道吗"
  - 例句1：나보고 기다리라고 했어.（让我等着。）
  - 例句2：천천히 하라고 했어.（让慢慢来。）
- 🎵**音变现象**：없거든 → [업꺼든]（ㅄ 紧音化）；생각해 → 连读

## 9. 그래, 생각을 해도 ┃ 好，就算要想 ┃ Sure.
- 📍**单词**：그래 = 好/行（回应）｜생각 = 想法/想｜-아/어도 = 即使……也
- 💬**短语**：생각을 해도 = 就算想（让步）
- 💬**句型/接口**：动词 + 아/어도 = "即使……也……"（让步连接）
  - 例句1：가도 돼요?（去也行吗？）
  - 例句2：힘들어도 해요.（累也要做。）
- 🎵**音变现象**：해도 → [해도]，ㅎ 弱化自然；생각을 → 连读

## 10. 집에 가서 하자, 알았지? ┃ 回家再想吧，知道了吗？ ┃ Let's think about it at home.
- 📍**单词**：집 = 家｜-에 가서 = 去……然后｜알다 = 知道｜-지 = 确认/叮嘱语气
- 💬**短语**：알았지? = 知道了吧？（征求同意/叮嘱）
- 💬**句型/接口**：动词 + 아/어서 = "……然后/因为……"；句尾 -지? = "……吧？"
  - 例句1：내일 만나서 하자.（明天见了再弄吧。）
  - 例句2：그렇지?（对吧？）
- 🎵**音变现象**：알았지 → [아랐찌]（ㅆ 紧音化）；집에 → [지베] 连读

## 11. 자, 일어나, 일어나 ┃ 来，起来，起来 ┃ Come on. Up you go.
- 📍**单词**：자 = 来（催促）｜일어나다 = 起来
- 💬**短语**：일어나 重复 = 快起来（反复催促）
- 💬**句型/接口**：动词 + 아/어（命令），重复表急切
  - 例句1：빨리, 빨리.（快点，快点。）
  - 例句2：가, 가.（走，走。）
- 🎵**音变现象**：일어나 → [이러나] 连读顺滑

## 12. 나 진짜 너무 화나고 너무 답답해 ┃ 我真的又气又憋屈 ┃ I'm so angry and frustrated.
- 📍**单词**：화나다 = 生气｜답답하다 = 憋闷/郁闷（心里堵）｜너무 = 太
- 💬**短语**：화나고 답답해 = 又气又闷（两个形容词并列）
- 💬**句型/接口**：形容词/动词 + 고 = "……并且……"（并列连接）
  - 例句1：예쁘고 착해요.（又漂亮又善良。）
  - 例句2：배고프고 피곤해요.（又饿又累。）
- 🎵**音变现象**：화나고 → 连读；답답해 → [답따패]（ㄷ 紧音化）

## 13. 내가 언제 그런 말을 했을까? ┃ 我什么时候说过那种话？ ┃ When did I ever say that?
- 📍**单词**：언제 = 什么时候｜말 = 话｜-했을까 = 会……吗（推测疑问）
- 💬**短语**：그런 말을 하다 = 说那种话
- 💬**句型/接口**：动词 + 았/었을까? = "（过去）会……吗？"（自问/反问）
  - 例句1：내가 그걸 알았을까?（我会知道那个吗？）
  - 例句2：그가 왔을까?（他来了吗？）
- 🎵**音变现象**：했을까 → [해쓸까]（ㅆ 紧音化）；말을 → 连读

## 14. 알았어, 똑바로 ┃ 知道了，好好走 ┃ I get it. Just walk straight.
- 📍**单词**：알았어 = 知道了（口语应答）｜똑바로 = 好好地/直直地
- 💬**短语**：똑바로 = 端端正正/好好（副词）
- 💬**句型/接口**：알았어 = 알겠어 的口语缩略；똑바로 作副词修饰动词
  - 例句1：똑바로 앉아.（坐正。）
  - 例句2：똑바로 말해.（好好说。）
- 🎵**音变现象**：알았어 → [아라써] 连读 + 紧音化；똑바로 → [똑빠로]（ㄱ 紧音化）

## 15. 똑바로 걸어 봐, 똑바로 걸어 / 알겠어 ┃ 好好走一个看看，好好走 / 知道了 ┃ Okay. / Walk straight.
- 📍**单词**：걷다 = 走（词干 걸-）｜-아/어 봐 = 试……看｜알겠어 = 知道了（标准而稍正式）
- 💬**短语**：걸어 봐 = 走走看（试探/示范）
- 💬**句型/接口**：动词 + 아/어 보다 = "试试……"；-아 봐 = "……看看"
  - 例句1：먹어 봐.（尝尝看。）
  - 例句2：해 봐.（试试看。）
- 🎵**音变现象**：걸어 봐 → [거러 봐] 连读；알겠어 → [알게써]（ㅆ 紧音化）

## 16. 제대로 좀 걸어 ┃ 给我好好走 ┃ Walk straight.
- 📍**单词**：제대로 = 好好地/正确地｜좀 = 一点/请（缓和语气）｜걷다 = 走
- 💬**短语**：제대로 좀 = 稍微好好地（带点不耐烦）
- 💬**句型/接口**：副词 + 좀 + 动词命令 = "给我……一点"（催促里带情绪）
  - 例句1：제대로 좀 해.（给我好好做。）
  - 例句2：좀 빨리 와.（快点来。）
- 🎵**音变现象**：걸어 → [거러] 连读
