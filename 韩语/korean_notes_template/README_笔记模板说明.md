## 六、铁律（踩过的坑）

0. 🔴🔴 **解析源 docx 时，语法讲解小点也用 `1. 2. 3.` 编号** → 只按「数字开头」判台词会把 `2. 动词词干 + -는 거야`、`3. 动词词干 + -는데` 误当台词。**必须双重判定：韩文开头 + 序号递进**。（2026-10-12 血泪）
1. 🔴 单词汇总**不要混入语法词尾**
2. 🔴 不要重复加序号（韩语行已有 1. 2.）
3. 🔴 不要用 PDF→docx 转换（串行），必须原生生成
4. 🔴 下载按钮必须用服务器直链，不要 JS（微信拦截）
5. 🔴 例句要连排 `1. / 2.` 编号，不要合并成一行
6. 🔴 改任何线上文件前先备份
