台词逐句精讲 26 句
1. 공항에서 나오자마자 너무 추운 거야
一出机场，冷得不行
The moment I got out of the airport, it was freezing.
单词：공항 机场 · 나오다 出来 · -(자)마자 一…就…
💬 短语나오자마자 — 一出来就（立刻）
📌 句型动词 + -자마자「一…就…」；-는 거야「（口语）陈述/感叹语气」。
例句：
1.집에 도착하자마자 잤어 → 一到家就睡了
2.보자마자 알아봤어 → 一看就认出来了
用法：-자마자 强调紧接着发生
🎵 音变 나오자마자 [나오자마자]；추운 거야 → 운 거 连读 [추운 거야]
2. 옷 몇 벌 사 입어야겠다 싶어서 택시 세우고 내리는데
想着得买几件衣服穿，拦了出租车刚下车
I thought I should buy some clothes, so I took a taxi and got out...
单词：몇 벌 几件 · 사다 买 · 입다 穿 · 택시 세우다 拦出租车
💬 短语옷을 사 입다 — 买衣服穿；택시를 세우다 — 打车（拦车）
📌 句型-아/어야겠다「得…了/该…了」；싶어서「想着…于是」；-는데 句末留话头。
例句：
1.좀 쉬어야겠다 → 得歇会儿了
2.먹고 싶어서 사 왔어 → 想吃了就买来了
用法：-아/어야겠다 表自我决心
🎵 音变 몇 벌 [몇뻘]（紧音化）；입어야겠다 [이버야겓따]
3. 딱 호진 씨가 보이더라
正好就看见浩镇你了
And there you were, Ho-jin.
单词：딱 正好、恰好 · 보이다 被看见、看得见
💬 短语딱 보이다 — 正好映入眼帘
📌 句型动词 + -더라「把亲身经历讲给对方听（回忆）」。
例句：
1.어제 갔더니 사람이 많더라 → 昨天去了，人好多啊
2.걔가 먼저 가더라 → 他先走了
用法：-더라 只用于第一人称亲历的回忆
🎵 音变 보이더라 [보이더라]；호진 씨 [호진씨]
4. 신기하지?
神奇吧？
Amazing, right?
单词：신기하다 神奇、新奇
💬 短语신기하지 — 神奇吧（寻求认同）
📌 句型形容词/动词 + -지?「确认对方想法…吧？」。
例句：
1.맛있지? → 好吃吧？
2.이상하지? → 奇怪吧？
用法：-지? 用于求认同、确认
🎵 音变 신기하지 [신기하지]（ㅎ 轻送气）；口音常读 [신기하쥐?]
5. 여기는 밤에는 이미 꽤 추워
这儿晚上已经很冷了
It's already quite cold here at night.
单词：밤 晚上 · 이미 已经 · 꽤 相当、挺
💬 短语밤에는 — 到了晚上（对比/话题）
📌 句型名词 + 은/는（话题/对比） ＋ 副词 꽤 表程度。
例句：
1.여기는 겨울에 꽤 추워 → 这儿冬天挺冷
2.이미 늦었어 → 已经晚了
用法：은/는 表对比或话题
🎵 音变 밤에는 [바메는]（自然连读）；꽤 [꽤]
6. 필요한 거 있으면 말해, 사다 줄게
有需要的就说，我给你买来
If you need anything, just say — I'll buy it for you.
单词：필요하다 需要 · 말하다 说
💬 短语사다 주다 — 买来给（某人）
📌 句型-(으)면「如果/的话」；-아/어 줄게「我来为你…」（意志·承诺）。
例句：
1.필요하면 말해 → 需要就说
2.내가 도와줄게 → 我来帮你
用法：-아/어 줄게 表主动为对方做的事
🎵 音变 있으면 [이쓰면]；줄게 [줄께]（ㅔ紧音）
7. 급하게 오느라 짐을 대충 싸서
来得急，行李随便收拾的
I packed in a hurry, so my luggage is a mess.
单词：급하게 匆忙地 · 짐 行李 · 대충 大致、随便
💬 短语짐을 싸다 — 收拾行李；대충 싸다 — 随便打包
📌 句型-느라(고)「因为（忙着）做…」（原因）；-아/어서 连接。
例句：
1.바쁘게 오느라 연락 못 했어 → 忙着赶来没联系你
2.대충 준비했어 → 随便准备了
用法：-느라 表因忙于某事而导致的结果
🎵 音变 급하게 [그파게]（ㅂ→ㅍ 激音化）；싸서 [싸서]
8. 이것저것 필요한 게 많아
这啊那啊需要的挺多
There's a lot I need, this and that.
单词：이것저것 这个那个、各种 · 많다 多
💬 短语이것저것 많다 — 要的东西很多
📌 句型名词 + 가/이 많다「…很多」；N이/가 表主语。
例句：
1.할 일이 많아 → 要做的事很多
2.살 게 많아 → 要买的东西很多
用法：게 是 것이 的口语缩写
🎵 音变 필요한 게 [필요한 게]；많아 [마나]
9. 호진 씨가 있어서 진짜 다행이다
有浩镇你在，真是万幸
It's really lucky that you're here, Ho-jin.
单词：다행이다 万幸、太好了
💬 短语다행이다 — 还好、真是万幸
📌 句型-아/어서（原因）＋ 다행이다「因为…真是幸好」。
例句：
1.네가 있어서 다행이야 → 有你在真幸运
2.안 다쳐서 다행이다 → 没受伤真是万幸
用法：-아/어서 다행이다 表庆幸
🎵 音变 있어서 [이써서]（ㅆ 音）；다행이다 [다행이다]
10. 근데 두 사람 아침 일찍 거기 왜 나온 거야?
不过你们俩怎么一大早就出来了？
But why did you two come out there so early in the morning?
单词：근데 不过、可是 · 두 사람 两位 · 아침 早上 · 일찍 早
💬 短语아침 일찍 — 一大早
📌 句型왜 + 动词 + -ㄴ/은 거야?「为什么…（的）？」（追问缘由）。
例句：
1.왜 온 거야? → 为什么来了？
2.어제 왜 안 왔어? → 昨天为什么没来？
用法：-ㄴ/은 거야? 追问原因、带疑惑
🎵 音变 근데 [근데]；나온 거야 [나온 거야]
11. 어, 근처 시장에 장 보러 나왔어
嗯，去附近市场买菜了
Yeah, we came out to shop at the market nearby.
单词：근처 附近 · 시장 市场 · 장(을) 보다 买菜、采购
💬 短语장 보러 가다/나오다 — 去买菜
📌 句型장을 보다「买菜」；动词 + -(으)러 + 移动动词「去/来做…」。
例句：
1.장 보러 갈까? → 去买菜？
2.커피 마시러 나왔어 → 出来喝咖啡
用法：장 보다 是买菜的固定说法
🎵 音变 장 보러 [장 보러]；나왔어 [나와써]
12. 시장?
市场？
The market?
💬 短语市场？—（重复对方词 + ?）表惊讶/追问
📌 句型回声疑问（重复关键词＋升调） — 表示意外、想再确认。
例句：
1.시장? → 市场？
2.진짜? → 真的？
用法：重复对方刚说的词来追问
🎵 音变 无特殊音变
13. 아, 여기서도 장 봐서 밥해 먹는 거야?
啊，在这儿也买菜做饭吃吗？
Oh, so you buy groceries here and cook too?
单词：여기서 在这里 · 밥하다 做饭
💬 短语밥해 먹다 — 做饭吃
📌 句型-아/어서（手段/顺序）串接两个动作；-는 거야?「…（是这么做的）吗？」。
例句：
1.여기서도 자주 밥해 먹어? → 在这儿也常做饭吃？
2.사서 먹는 거야? → 是买着吃吗？
用法：-아/어서 连接先后动作
🎵 音变 밥해 → [바패]（ㅂ+ㅎ 激音化）；먹는 [멍는]（ㄱ 鼻音化）
14. 하여튼 주호진
反正啊，周浩镇
Anyway, Joo Ho-jin...
单词：하여튼 总之、反正（口语）
💬 短语하여튼 — 不管怎样、反正
📌 句型하여튼 + 人名/话「反正啊，某某…」（话头/吐槽）。
例句：
1.하여튼 너는 특이해 → 反正你很特别
2.아무튼 알겠어 → 总之知道了
用法：하여튼 用来开启吐槽或总结
🎵 音变 하여튼 [하여튼]/常读 [하예튼]
15. 까다롭고 부지런해요
又挑剔又勤快
Picky and diligent.
单词：까다롭다 挑剔、难伺候 · 부지런하다 勤快
💬 短语까다롭고 부지런하다 — 又挑剔又勤快
📌 句型形容词 + -고 + 形容词（并列）；此处 -해요 敬语结尾（对长辈/客人）。
例句：
1.예쁘고 똑똑해요 → 又漂亮又聪明
2.바쁘고 피곤해요 → 又忙又累
用法：-고 并列两个形容词
🎵 音变 부지런해요 [부지런해요]（无特殊）
16. 그럼 무희 씨도 호진이 요리 먹어 봤겠네요?
那茂熙你也吃过浩镇做的菜吧？
Then you've tried Ho-jin's cooking too, Mu-hui?
单词：그럼 那么 · 요리 菜、料理
💬 短语먹어 봤다 — 吃过（试过）
📌 句型-아/어 보다「尝试做…」；-겠네요「推测并感叹想必…吧」。
例句：
1.한국 음식 먹어 봤어요? → 吃过韩国菜吗？
2.맛있겠네요 → 应该很好吃吧
用法：-아/어 보다 表经验；-겠네요 表推测感叹
🎵 音变 먹어 → [머거]（ㄱ 脱落连读）；봤겠네요 [봐겐네요]
17. 요리 잘하죠?
他做菜好吧？
He cooks well, doesn't he?
单词：요리 잘하다 菜做得好
💬 短语요리를 잘하다 — 擅长做菜
📌 句型잘하다「擅长」；-죠?「（口语）…吧？」（求认同）。
例句：
1.노래 잘하죠? → 唱歌好吧？
2.요리 잘하죠? → 做菜好吧？
用法：-죠? 是 -지요? 的缩略，求认同
🎵 音变 잘하죠 [잘하죠]（ㅎ 轻）；口音 [자라죠]
18. 모르겠는데요, 안 먹어 봐서
不知道呢，没吃过
I don't know — I haven't tried it.
单词：모르다 不知道 · -겠는데요 （委婉）…呢/其实…
💬 短语모르겠는데요 — 我也不太清楚呢（委婉）
📌 句型动词 + -겠는데요（委婉表达）；-아/어서 说明原因（因为没吃过）。
例句：
1.잘 모르겠는데요 → 不太清楚呢
2.아직 안 가 봐서 몰라요 → 还没去过所以不知道
用法：-겠는데요 让语气柔和、不把话说死
🎵 音变 먹어 → [머거]；봐서 [봐서]
19. 언제 한번 해 달라고 해요
让他哪天给你做一次
Ask him to make it for you sometime.
单词：언제 什么时候 · 한번 一次
💬 短语해 달라고 하다 — （替我）请他做一下
📌 句型动词 + -아/어 달라고 하다「让别人为我做…」；한번 表「找个机会」。
例句：
1.한번 해 달라고 해 봐 → 让他给你做一次
2.도와 달라고 했어 → 请他帮忙了
用法：-달라고 하다 是转达请求
🎵 音变 해 달라고 [해 달라고]；달라고 해요 [달라고 해요]
20. 진짜 잘해요

单词：진짜 真的
💬 短语진짜 잘해요 — 真的（做得）很好
📌 句型副词 진짜/정말 ＋ 잘하다 表强调赞赏。

25. 뭐, 어디 근처 식당이라도 들렀다 갈까?

💬 短语들렀다 가다 — 顺路去一下再去
📌 句型名词 + -이라도「哪怕是…也行」；动词 + -았다/-었다 가다「…了再去」。
例句：

🎵 音变 식당이라도 [식땅이라도]（紧音化）；들렀다 [들렀따]
26. 응, 아니야 뭐, 가서 먹지, 뭐
嗯，不用了，回去再吃吧
Nah, it's fine — we'll eat when we get there.
单词：응 嗯 · 아니야 不是、不用 · 가서 去了（서）
💬 短语가서 먹지, 뭐 — 回去（到了）再吃呗
📌 句型动词 + -지(요)/-지 뭐「就…吧（无所谓）」；-아/어서 连接。
例句：
1.그냥 가지, 뭐 → 算了就去呗
2.나중에 하지, 뭐 → 以后再弄呗
用法：-지 뭐 表随意的决定、无所谓
🎵 音变 가서 [가서]；먹지 [먹찌]（紧音化）
本课句型总结 20 组
① 动词 + -자마자 — 一…就…
强调两个动作紧接发生。
→ 나오자마자 너무 추운 거야 (一出来冷得不行) / 도착하자마자 잤어 (一到家就睡了)
② -아/어야겠다 — 得…了
表自我决心、必要。
→ 옷 몇 벌 사 입어야겠다 싶어서 (想着得买几件衣服穿) / 좀 쉬어야겠다 (得歇会儿了)
③ 动词 + -더라 —（回忆）…来着
把亲历的往事讲给对方听。
→ 딱 호진 씨가 보이더라 (正好就看见你了) / 어제 갔더니 사람이 많더라 (昨天去了人好多)
④ -지? — …吧？（求认同）
确认对方想法、求同意。
→ 신기하지? (神奇吧？) / 맛있지? (好吃吧？)
⑤ 名词 + 은/는 —（话题/对比）
提出话题或做对比。
→ 여기는 밤에는 이미 꽤 추워 (这儿晚上已经很冷了) / 여기는 겨울에 꽤 추워 (这儿冬天挺冷)
⑥ -(으)면 … -아/어 줄게 — 如果…我就…
条件＋承诺。
→ 필요한 거 있으면 말해, 사다 줄게 (有需要的就说，我给你买来) / 내가 도와줄게 (我来帮你)
⑦ -느라(고) — 因为（忙着）做…
表因忙于某事导致的结果。
→ 급하게 오느라 짐을 대충 싸서 (来得急行李随便收拾的) / 바쁘게 오느라 연락 못 했어 (忙着赶来没联系你)
⑧ 名词 + 이/가 많다 — …很多
表数量多。
→ 이것저것 필요한 게 많아 (这啊那啊需要的挺多) / 할 일이 많아 (要做的事很多)
⑨ -아/어서 다행이다 — 因为…真是幸好
表庆幸、万幸。
→ 호진 씨가 있어서 진짜 다행이다 (有你在真是万幸) / 안 다쳐서 다행이다 (没受伤真是万幸)
⑩ 왜 -ㄴ/은 거야? — 为什么…？
追问缘由，带疑惑。
→ 아침 일찍 거기 왜 나온 거야? (怎么一大早就出来了？) / 왜 온 거야? (为什么来了？)
⑪ 장을 보다 + -(으)러 — 去买菜
买菜＋移动目的一句话搞定。
→ 근처 시장에 장 보러 나왔어 (去附近市场买菜了) / 장 보러 갈까? (去买菜？)
⑫ -아/어 보다 / -겠네요 — 尝试…／想必…吧
经验＋推测感叹。
→ 요리 먹어 봤겠네요? (你吃过他做的菜吧？) / 맛있겠네요 (应该很好吃吧)
⑬ -죠? — …吧？
口语求认同，比 -지? 更柔和。
→ 요리 잘하죠? (他做菜好吧？) / 노래 잘하죠? (唱歌好吧？)
⑭ -겠는데요 — 委婉不太…
让语气柔和、不把话说死。
→ 모르겠는데요, 안 먹어 봐서 (不知道呢，没吃过) / 잘 모르겠는데요 (不太清楚呢)
⑮ -아/어 달라고 하다 — 让别人为我做…
转达请求。
→ 언제 한번 해 달라고 해요 (让他哪天给你做一次) / 도와 달라고 했어 (请他帮忙了)
⑯ -(으)니까 — 因为/一说到…
表原因、依据。
→ 밥 얘기하니까 배고프다 (一说吃的我就饿了) / 보니까 먹고 싶어 (一看就想吃)
⑰ 얼마나 걸리다? — 要多久？
询问所需时间。
→ 숙소까지는 얼마나 걸려? (到住处要多久？) / 시간이 얼마나 걸려요? (要花多长时间？)
⑱ -(으)ㄹ 텐데 — 大概会…
表推测，句末留话头。
→ 한 30분 정도 걸릴 텐데? (大概要30分钟吧？) / 늦을 텐데 (怕要迟到了)
⑲ 名词 + -이라도 — 哪怕是…也好
退而求其次。
→ 식당이라도 들렀다 갈까? (要不附近找家餐厅顺路吃了？) / 커피라도 마실까? (哪怕是喝杯咖啡？)
⑳ -지 뭐 — 就…呗
随意决定、表示无所谓。
