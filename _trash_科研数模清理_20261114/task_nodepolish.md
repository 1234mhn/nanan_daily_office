## 改造要求

### 1. 每个关卡加一张「手绘感 SVG 小插画」（核心）
- **纯内联 SVG**（不许外链图片），风格统一：线条圆润、马卡龙配色、扁平卡通风
- 每个词配一个能表意的小图。可以为每个词单独画，也可以**按词分组复用**（优先复用，控制工作量）
- 建议的图标映射（inline SVG，viewBox 0 0 24 24 或 32 32）：
  - 일어나다 起床 → 床 + 上升箭头
  - 알람 闹钟 → 闹钟
  - 늦잠 睡懒觉 → 床 + Zzz
  - 깨다 醒 → 睁开的眼睛
  - 5분만 더 再睡5分钟 → 枕头 + 时钟
  - 세수하다 洗脸 → 水龙头 + 水滴
  - 양치하다 刷牙 → 牙刷
  - 씻다 洗 → 花洒 + 水
  - 머리를 감다 洗头 → 头发 + 泡沫
  - 머리를 말리다 吹头发 → 吹风机
  - 수건 毛巾 → 毛巾
  - 칫솔 牙刷 → 牙刷（与 양치하다 区分：这个画物品）
  - 거울 镜子 → 镜子
  - 옷을 입다 穿衣 → T恤
  - 갈아입다 换衣 → 两件衣服 + 循环箭头
  - 이불 被子 → 叠好的被子
  - 아침 早上 → 太阳
  - 아침을 먹다 吃早饭 → 碗 + 筷子
  - 나가다 出门 → 门 + 箭头
  - 서두르다 赶紧 → 速度线 + 跑动
  - 피곤하다 累 → 汗滴 + 下垂眼
  - 졸리다 困 → 眼睛半闭 + Zzz
  - 개운하다 神清气爽 → 闪光 + 笑脸
  - 일어서다 起身 → 站立小人
- 图标要能在 64~68px 圆内清晰显示（描边够粗，不要细节过多）
