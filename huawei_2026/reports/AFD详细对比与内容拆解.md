## 1.3 三题最难的地方各是什么

**A题：目标函数是黑箱。**
Makespan 只能由官方评估器（附录B/C/D三阶段仿真）算出。这导致：不能求导、不能解析松弛，只能"生成候选→调用评估器→迭代改进"。而且**评估器单次调用成本高**，搜索预算极其有限。最难的洞察是：Q1 里 Cinner=Ccross，"把强通信子图放同核"根本不省通信。

**F题：建模设计没有标准答案。**
题面明确说"模型形式自定""鼓励创新"。难在你得自己设计一个"Q=1时退化为经典标度律"的广义形式，还得让它能被数据拟合出来。半合成数据 B6-B8 不能当真实观测用，这是个陷阱。

**D题：规则密度极高。**
真正难的不是数学（都是初等公式），而是**规则条目多到容易漏**。一个"投送后要从30m重新爬升"忘了，全部数值报废。

### ② 用到的数学/公式（题目直接给的）

**经典标度律**
$$L(N,D) = E + A N^{-\alpha} + B D^{-\beta}$$

**算力模型（Q3，三段）**
- 基础训练：$C_{train} = 6ND$
- 质量提升：$C_Q = D[g(Q) - g(Q_0)]^+$

**成本函数三选（附录B.1）**
| 类型 | 形式 | 参数 |
|---|---|---|
| 指数型 | $g(Q)=\gamma e^{\lambda Q}$ | γ=10⁷, λ=6.0 |
| 幂函数型 | $g(Q)=\gamma Q^{\lambda}$ | γ=5×10⁹, λ=4.0 |
| 对数渐进型 | $g(Q)=\gamma \ln(1+\lambda Q)$ | γ=2×10⁹, λ=10.0 |

**预算档位**：C = 10¹⁹ / 10²² / 10²⁴ FLOPs（至少考察三个量级）

**约束**：单纯形约束 $p_i \ge 0,\ \sum_i p_i = 1$

### ② 用到的数学/公式（题目直接给的）

**等效航程（载荷相关）**
$$L_g(q) = L_{g0} - \frac{L_{g0}-L_{gF}}{Q_g^{3/2}} q^{3/2},\quad 0 \le q \le Q_g$$

**航段飞行时间**
$$t_{gij} = \frac{h_{ij}^+}{v_g^{\uparrow}} + \frac{d_{ij}}{v_g^{c}} + \frac{h_{ij}^-}{v_g^{\downarrow}}$$

**航段能耗**
$$E_{gij}(q) = E_{gij}^{hor}(q) + E_{gij}^{up}(q)$$

**返航安全余量**
$$E_p^T = \sum_{(i,j)\in p} E_{gij}(q_{pij}) \le (1-\rho_g) E_g^{use}$$

**两阶段充电模型（90%分界，65%/35%）**
$$t_{chg}(s) = \begin{cases} T_{full}[0.65(0.90-s)/0.90 + 0.35], & 0\le s<0.90\\ T_{full}\cdot 0.35(1-s)/0.10, & 0.90\le s\le 1\end{cases}$$

**地形遮挡变量**：$b_{ij}^t \in \{0,1\}$

**接收门限**：$P_{th}^b = P_{sens}^b + M^b$

**最大允许传播损耗**：$L_{max}^{a\to b} = P_t^a + G_t^a + G_r^b - L_{sys} - P_{th}^b$

**双向链路取小**：$L_{max}^{a\leftrightarrow b} = \min(L_{max}^{a\to b}, L_{max}^{b\to a})$

**自由空间传播损耗**：$L_{FSPL,ij}^t = 32.45 + 20\log_{10}f + 20\log_{10}D_{ij}^t$

**总传播损耗**：$L_{path,ij}^t = L_{FSPL,ij}^t + L_{obs}b_{ij}^t$

**链路可用性**：$A_{ij}^t = 1 \iff L_{path,ij}^t \le L_{max}^{i\leftrightarrow j}$

### ④ 用到的技术点（物理规则，最易漏）
