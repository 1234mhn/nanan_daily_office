## 二、逐题速览

### A题 · 多核NPU切图与调度
- **四问**：①场景A切图调度 ②场景B（核内复用）③共享L2 ④（无）
- **实际三问**：问题1/2/3
- **核心决策**：切图 / 核心分配 / 同核执行顺序
- **主目标**：Makespan；次目标：额外DDR搬运量、Cache命中率
- **关键参数**：L1=524288B，UB=131072B，DDR=60B/cycle，L2=1MB/250B/cycle
- **交付**：1~5核加速比折线图 + 逐用例附录 + Python脚本
- **必读附录**：A硬件架构 / B格式与运行 / C核内调度 / D多核模拟

### B题 · 燃料电池冷启动
- **四问**：①一维单电池冷启动模型+验证 ②5片电堆电流加载优化+最低启动温度 ③辅助加热（预加热 vs 恒功率）④动态功率控制+三种预冷工况
- **主目标**：①误差最小 ②min ts ③④min 辅助加热能耗
- **核心耦合**：冰↑→孔隙率↓→扩散↓→氧传输↓→电压↓→产热↓→冰↑（正反馈死锁）
- **关键参数**：qmax=20 C/cm²，jmax=0.5 A/cm²，h=40 W/m²K，A=25 cm²，Eth=1.48V
- **交付**：表1/表2验证表、表3策略对比、表4辅助策略、表4工况对比 + 程序压缩包（B+队号）
- **必备**：附件1（参数）、附件2（-20℃/-25℃实验数据）

### C题 · 脑电计算模型
- **三问**：①保特征降噪+提取视觉响应+拟合曲线 ②LGN→皮层→头皮机理模型，区分左右三角刺激 ③认知宏观模型（海马体+LGN）+验证
- **数据**：4组.mat（VisualCogA/B_Task-1/2），SampleRate=256，10通道
- **通道用法**：1-3原始（**只能用**）/ 4-6 decon（**禁用**）/ 7 ECG / 8 视觉提示(-1左+1右) / 9 应答(-2左+2右) / 10 时间戳
- **尺度模型**：微观LIF / 介观Wilson-Cowan / 宏观Kuramoto序参数
- **交付**：EEG计算模型+特征表示+认知模型验证

### D题 · 无人机运输与通信协同
- **四问**：①单点往返能力+货箱组批 ②异构多点多架次调度 ③通信约束下运输+中继联合调度 ④任务分区（2组/3组）与资源配置
- **场景规模**：1调度中心O01 + 15服务区 + 80不可拆货箱 + 3机型8架 + 共享电池 + 中继机 + 30m DEM
- **主目标**：配送及时性、任务完成时间、总能耗、架次数
- **关键规则**：巡航高度=DEM最高点+50m；往返安全余量；两阶段充电模型（90%分界，65%/35%）
- **通信规则**：地形遮挡判定 + 双向链路预算取小值 + 两段链路（禁多跳中继）
- **交付**：路线/架次/逐箱送达时刻/资源使用 + 两分区方案对比

### E题 · 多模态情感识别
- **三问**：①三模态特征提取+时序对齐 ②模态局部缺失鲁棒预测 ③可解释性预测（证据定位）
- **数据**：附件1（100条原始视频+label-100.xlsx）/ 附件2（aligned_50.pkl、unaligned_50.pkl，各4850条）/ 附件3（缺失测试集）/ 附件4（可解释测试集）
- **特征形状**：aligned 文本(50,768)/语音(50,74)/视觉(50,35)；unaligned 语音视觉(500,·)
- **读取**：`data['train']['audio'][j]`（**不是** `data['train'][j]['audio']`）
- **指标**：极性 Accuracy/F1；强度 MAE/Pearson
- **禁令**：只能用CMU-MOSEI；aligned/unaligned 选定一套不可混；提交禁出现身份信息；附件≤50MB

### F题 · LLM算力资源配置
- **四问**：①数据质量Q+冲突消解+17域配比p→Loss ②广义标度律（含Q、p） ③算力约束下N/D/Q/p联合优化+结构性转移 ④规模vs技术进步贡献分解+前沿预测
- **算力模型**：C = 6ND + D[g(Q)-g(Q0)]⁺ + η·N·D·Lctx，η=2e-4，Lctx_crit=6/η=30000
- **预算档位**：C = 10^19 / 10^22 / 10^24 FLOPs
- **成本函数三选**：指数型 g=1e7·e^(6Q) / 幂函数型 g=5e9·Q^4 / 对数渐进型 g=2e9·ln(1+10Q)
- **数据映射**：A1-A18 质量与配比 / B1-B12 标度律 / C1-C10 演进与Benchmark
- **交付**：Q评分、广义标度律、最优配置与结构转移、前沿预测+不确定性

## 三、按维度横向对比

### 1. 按"数学建模含量"排序
B(★★★★★) > C(★★★★★) > A(★★★★) = D(★★★★) = F(★★★★) > E(★★★)

### 2. 按"上手难度"排序（越左越易）
F(★) < D(★★) < A(★★★) < E(★★★★) < B(★★★★★) = C(★★★★★)

### 3. 按"工时消耗"排序（越左越省）
F(★★★) = D(★★★) < A(★★★★) < B = C = E(★★★★★)

### 4. 按"结果客观性"排序（越左越可验）
A(评估器打分) > F(数值可验) > E/D(需真跑) > B(对比实验曲线) > C(开放主观)

### 5. 按"翻车风险"排序（越左越安全）
F < D < A ≈ E < B < C

### 6. 按"与你方向（医学+AI/医疗大模型/多模态）契合度"
E(多模态AI，直接对口) ≈ F(LLM，直接对口) > C(神经/医学，方向对口但太难) > A(DAG调度，沾AI底层) > D(物流优化，不对口) > B(能源物理，不对口)
