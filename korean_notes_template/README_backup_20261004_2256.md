# 韩语精讲笔记 · 标准模板（2026-10-04 用户定稿）

> **触发词**：用户说「生成第X课精讲笔记」/「第X课笔记」 → 按本模板生成。
> **基准样板**：第53课（买菜与做饭）—— 以此为准。

## 一、内容结构（固定三段）

### 1. 台词逐句精讲（每句格式）
```
1. <韩语原句>              ← 韩语行自带序号，不再另加 01/02 小序号
<中文翻译>
<英文翻译>（灰色斜体）

[浅灰底块] 单词：<词> <含义> · <词> <含义> · ...
💬 短语 <短语内容>
📌 句型 <句型内容>

例句：
1. <例句1>
2. <例句2>
用法：<用法说明>

🎵 音变 <音变说明>
```

### 2. 本课句型总结
每组：句型标题 + 含义说明 + 例句（灰字）

### 3. 本课单词汇总（表格）
- **两栏表格**，无表头
- 每格内容：`单词 含义`（单词加粗深色，含义浅灰）
- **只放真单词（名词/动词/形容词/副词）**
- 🔴 **过滤掉语法词尾/句型**（如 `-(으)르려면`、`-대서`、`-거든요`、`-(이)랑`、`-겠죠?`、`-았/었으면 좋겠다`、`-아/어 봐야겠다` 等）——这些属于「句型总结」，不进单词表

## 三、输出形式（三件套）

1. **HTML 版** —— 干净排版（白底、细灰分隔线、灰底块）
   - 右下角两个按钮：**📄 下载 Word**、**📕 下载 PDF**
   - 🔴 按钮必须是**服务器直链 `<a href>`**，**禁用 JS 生成下载**（微信会拦，无法下载）
2. **Word 版（.docx）** —— **用 python-docx 原生生成**（🔴 严禁 HTML→PDF→docx 转换，会串行）
3. **PDF 版** —— 由 HTML 转（版式锁定）

## 六、铁律（踩过的坑）

1. 🔴 单词汇总**不要混入语法词尾**
2. 🔴 不要重复加序号（韩语行已有 1. 2.）
3. 🔴 不要用 PDF→docx 转换（串行），必须原生生成
4. 🔴 下载按钮必须用服务器直链，不要 JS（微信拦截）
5. 🔴 例句要连排 `1. / 2.` 编号，不要合并成一行
6. 🔴 改任何线上文件前先备份
