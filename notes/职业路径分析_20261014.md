# 框架一：Circle of Competence（能力圈）

**When to Use 检查**：本分析中多处论断会被当作「事实」使用（能力、适配度），且错误判断成本高（影响人生路径）→ **适用**。
**When NOT to Use 检查**：用户自述事实属于本 session 可引用来源（grounded）；对「用户能力」的判断多为 partial，需标不确定性。

## 逐条按 Procedure 执行

### 1. 待判定断言（Name the claim）

| # | 断言 | Zone | Evidence | Wrongness cost | Action |
|:--|:--|:--|:--|:--|:--|
| C1 | 用户韩语发音像本地人 | grounded（用户自评） | 自述 | low | answer（原样采信为自评，非客观认证） |
| C2 | 用户具备「简化复杂问题」能力 | partial | 自评，无外部佐证 | medium | answer-with-uncertainty |
| C3 | 用户是双语博主、粉丝683/481 | grounded | 自述具体数字 | low | answer |
| C4 | 自媒体「无法变现」是现状 | grounded | 自述 | low | answer |
| C5 | 私信问 APP 是「真需求」 | **ungrounded** | 仅单条私信，无转化数据 | medium | **abstain/ask**（不确定是不是真需求，已在档案中标注不确定） |
| C6 | 研一方向 = 医学+AI | **partial/ungrounded** | 档案写「待确认」 | **high**（决定研究方向选型） | **fetch-then-answer（=向用户确认）** |
| C7 | 用户「适合/不适合」某职业 | **ungrounded** | 无实际从事证据 | high | abstain → 只做「能力证据映射」，不下适配结论 |
| C8 | 用户「很少接触社会」 | grounded | 自述 | low | answer |
| C9 | 用户「很想证明自己」 | **ungrounded（假设）** | 用户未直接说 | medium | 标为假设，不作事实使用 |

### 2. 证据边界结论（能说什么 / 不能说什么）

**能说的（grounded）：**
- 用户有一条**可复述的、跨语言+跨销售+跨教学的实操经历链**（销售/讲师/双语内容）。
- 用户具备**输出型技能**（写字、唱歌、韩语发音、吉他、讲解）——均为"面向人表达"类。
- 自媒体处于**有内容无商业闭环**阶段。

**不能说的（ungrounded，禁编）：**
- ❌ 不能说用户"适合做知识博主/教培/科研"——无从事成果证据。
- ❌ 不能断言医学+AI 方向对用户有利——方向本身待确认。
- ❌ 不能断言私信=市场需求——无转化证据。

**⚠ 能力圈核心发现：** 用户自评的专长**几乎全部落在「面向人的表达」集群**（写字/唱歌/韩语/吉他/讲解），而**学历路径落在「软件工程 → 医学+AI」的抽象技术集群**。这两个集群**当前没有 grounded 证据表明已打通**——这是最值得标记的能力边界缺口，不是缺陷，是**未被验证的连接假设**。

### 3. When NOT 遵守

- 用户自述的学历、粉丝数、经历 = grounded，**不做虚假谦逊、不加 hedge**。
- 对「适配度」类判断 = ungrounded，**不回答**，改列「需要哪些证据才能判断」。

## Circle of Competence 输出

```text

Wrongness cost: high

          要判断需先获得：①医学+AI方向确认 ②任何一次内容/教学的真实转化数据

Wrongness cost: low

          与学历集群 {软件工程, 医学+AI} 的连接尚无证据，标记为待验证假设
```

# 框架二：Second-Order（二阶效应）

**When to Use 检查**：职业路径是长期耦合决策，显性收益下有回弹/复利效应 → **适用**。
**When NOT to Use 检查**：本问题非"局部可逆小编辑"，非纯机械改动 → 不触发排除条件。

## 1. 三个候选方向（由证据推出的可选项，非推荐）

- **选项 A：自媒体/content 为主路径**（双语内容 + 教培招生）
- **选项 B：学历专业路径**（医学+AI 科研/技术岗）
- **选项 C：双线并行**（在读期间做自媒体，毕业后按方向择一）

## 2. 按 Procedure 逐步执行（含 S1 考研4年、S2 证明自己）

---
### 决策 A：把「自媒体+教培招生」作为长期主路径

- **first_order:** 持续产出视频 → 吸引学生/粉丝 → 逐步变现
- **chain:**
  - order 2｜effect: 内容更新压力持续 → actors: 用户本人 → p: high → when: immediate → feedback: **reinforce**（做得越多越离不开，形成日常节奏）
  - order 2｜effect: 招生/涨粉速度低于预期，无正反馈 → actors: 用户 → p: high → when: next_cycle → feedback: **counteract**（动力衰减）
  - order 3｜effect: 若 2-3 年无变现，S1 的「考研4年」沉没成本叠加 → 产生"又白干一场"认知 → actors: 用户 → p: med → when: next_cycle → feedback: **reinforce S2**（更急于证明自己 → 可能病急乱投医换赛道）
  - order 3｜effect: 若成功变现，形成"个人IP+教培"漏斗 → actors: 用户+平台 → p: med → when: at_scale → feedback: reinforce
- **scale_if_universal:** 若所有双语学习者都做同类内容，注意力被稀释，单账号涨粉更难（供给端拥挤）。
- **revised_decision:** **modified** — 把它当作"两条腿之一"而非唯一主路径；且必须**先补一个商业闭环实验**，而非无目标日更。
- **mitigations:** 设 3 个月变现/留资小实验（如单一钩子视频→私信转化率），有数再决定加码与否。

---
### 决策 B：把「医学+AI 科研/技术」作为长期主路径（⚠ 方向待确认）

- **first_order:** 在读期间聚焦专业 → 毕业进入 AI/医疗AI 岗位或读博
- **chain:**
  - order 2｜effect: 专业技能累积但与"面向人的表达"技能割裂 → actors: 用户 → p: med → when: next_cycle → feedback: **counteract S1**（技能不能停的自媒体诉求被挤压）
  - order 2｜effect: 2-3 年"接触社会"计划与实验室节奏冲突 → actors: 用户+导师 → p: med → when: next_cycle → feedback: counteract
  - order 3｜effect: 若专业成果顺利，形成稀缺的"医学+AI+双语"交叉标签 → actors: 用户+就业市场 → p: med → when: at_scale → feedback: **reinforce**（这是 A 路径没有的护城河）
  - order 3｜effect: S1 的"证明自己"若投射到学术（发论文/硬成果），动机与路径一致 → p: med → when: next_cycle → feedback: reinforce
- **scale_if_universal:** AI 人才供给放大 → 单靠"会写代码"不稀缺，**必须叠加不可替代的交叉标签**才站得住。
- **revised_decision:** **modified** — 不放弃，但要**明确把它与自媒体做成同一个交叉标签**，而非两条互不相干的线。
- **mitigations:** 先确认方向（C6）；对齐导师/课题与"接触社会"的可行性；把双语能力设计进专业叙事（如医疗AI的国际传播/科普）。

---
### 🔴 专项处理 S1：考研 4 年

- **二阶解读（不评判、只追踪）：**
  - order 1｜已发生：4 年时间成本已沉没 → **不可回收**（Reversibility 视角：Type 1 已不可逆）。
  - order 2｜潜效应：4 年沉没成本易产生**"必须用这个学历兑现"的锁定倾向** → actors: 用户 → p: **high** → when: next_cycle → feedback: **reinforce**（越投入越难转向，即使方向未必最优）。
  - order 2｜信号（Signal）：连续 4 年重复备考 = 可证明的**抗压/目标坚持**证据（正面信号），但也可能是**路径依赖/不愿重新评估假设**的证据（负面信号）——**两种解释并存，无数据判别，标为不确定**。
  - order 3｜风险：若把"上岸"本身当成终点而非手段，则读研期间可能缺乏对"毕业后要走哪条"的主动规划 → p: med → feedback: counteract（对长期路径不利）。
- **scale_if_universal:** n/a（个人历史，非可放大选项）
- **revised_decision:** 决策时**不得以"已经读了4年"作为继续某方向的理由**；只以"未来3年投入产出"评估。
- **mitigations:** 明确区分"沉没成本"（不该影响决策）与"坚持力信号"（可以作为自我认知的正资产）。

---
### 🔴 专项处理 S2（假设）："很想证明自己"

> ⚠ **这是假设，用户未直接陈述。以下仅为条件式推理，不得当作事实。**

- **二阶风险链（若假设成立）：**
  - order 2｜effect: "证明自己"驱动 → 倾向**选择能快速被看见的方向**（涨粉、被认可）→ actors: 用户 → p: med → when: immediate → feedback: **reinforce**（短期正反馈上瘾）
  - order 3｜effect: 可能反复横跳赛道以追逐"被认可感"，**每次归零重来** → p: med → feedback: counteract（长期路径无法积累）
  - order 3｜effect: 若把"证明"锚定在**可累积的长期成果**（过硬技能/作品/论文），则动机与路径同向 → p: med → feedback: reinforce
- **revised_decision:** 与方向选择强相关——**方向筛选标准应加一条：该方向能否在 2-3 年内产生"可被外部验证的累积成果"**，而非只是"被看见的即时反馈"。
- **mitigations:** 把"证明自己"从**情绪驱动**转为**指标驱动**（设定可量化里程碑）。

## Second-Order 输出

```text
decision: 为长期路径做方向选择（A 自媒体 / B 专业 / C 并行）
first_order: 选定方向并持续投入 → 获得该方向的初级回报
chain:
  - order: 2 | effect: 内容/科研的持续投入形成日常锁定 | actors: 用户 | p: high | when: immediate | feedback: reinforce
  - order: 2 | effect: 无正反馈导致动力衰减 | actors: 用户 | p: high | when: next_cycle | feedback: counteract
  - order: 2 | effect: 4年沉没成本诱发放大投入倾向 | actors: 用户 | p: high | when: next_cycle | feedback: reinforce
  - order: 3 | effect: 长期无变现 → 叠加"又白干"认知 → 急换赛道 | actors: 用户 | p: med | when: next_cycle | feedback: reinforce(S2)
  - order: 3 | effect: 双语×专业交叉标签形成稀缺性 | actors: 用户+市场 | p: med | when: at_scale | feedback: reinforce
scale_if_universal: 单一技能（会代码/会做内容）在供给放大后不稀缺，只有交叉标签保值。
revised_decision: modified — 走"交叉标签"路线：不做两条互不相干的线，而把双语表达×专业做成一件事
mitigations: ①三个月小实验验证变现 ②决策时不引用沉没成本 ③设定可量化里程碑替代"被看见"
```

# 框架三：Reversibility（可逆性）

**When to Use 检查**：需要判断"哪些决策值得深思、哪些应快速试" → **适用**。
**When NOT to Use 检查**：未在本 session 已分类过；非纯 trivial；非外部强制 → 不触发排除。

## 按 Procedure 逐项分类

### R1｜"未来2-3年去接触社会"这个计划
- **Undo path:** 计划本身是时间安排，可随时调整/提前结束/延长 → 撤销成本低。
- **Class:** **Type 2**（数天-数周可改）＋ 部分 Type 1.5（时间一旦花掉不可回收，但方向可改）
- **Acting downside / recovery:** 若"接触社会"方式选错（如投入低价值兼职），时间损失中等但可调头。
- **Not-acting permanent loss:** 不接触社会 → **永久错过积累社会经验/人脉的窗口**（这是 Type 1 性质的机会成本）。
- **Staging:** 用"低成本多触点"方式接触（短期实习/项目/线上协作），而非长期锁定单一岗位。
- **Process depth:** **pilot**
- **Commitment:** 立即启动低成本接触，保留随时切换权。

### R2｜自媒体内容方向（具体选题/账号定位）
- **Undo path:** 改选题、换账号、删视频，天级可逆。
- **Class:** **Type 2**
- **Process depth:** **decide-now + monitor**
- **Commitment:** 快速多发、快速淘汰，别反复纠结"录什么"——纠结本身才是最大成本。

### R3｜学历专业方向（医学+AI，已投入）
- **Undo path:** 转方向/换课题有行政与时间成本；退学=高成本。
- **Class:** **Type 1（已部分不可逆）** — 4 年备考+在读投入已沉没。
- **Acting downside / recovery:** 认准当前方向走下去，downside 可控（在读中，仍有调整课题空间），recoverable=yes（课题层面）。
- **Not-acting permanent loss:** 若因犹疑而不深耕，可能两头空 → 学历价值打折。
- **Staging:** **把"是否读博/是否进医疗AI岗"延后到有更多信息时决定**；当前只锁定"把书读好"这一可逆性较高的动作。
- **Process depth:** **full deliberation（针对毕业去向）** / **decide-now（针对当下学业投入）**
- **Commitment:** 学业投入立即执行；毕业去向留到研二再定（保留选项）。

### R4｜"是否把自媒体作为长期职业"这个大决策
- **Undo path:** 无法"撤销"已花的时间，但可以把自媒体从"主路径"降为"副线"——**角色可逆，投入不可逆**。
- **Class:** **Type 1.5** — 2-3 个月可验证，但投入的时间不可回收。
- **Staging（关键）：** **不要现在就all-in**。把它转化为 3 个月 Type 2 实验：设定"留资/成交"可验证指标。
- **Process depth:** **pilot**
- **Commitment:** 先跑实验拿数据，再决定是否加码。

## Reversibility 输出

```text
Decision: 是否把自媒体/教培作为长期主职业
Undo path: 时间不可回收，但角色可从"主业"降级为"副线"（可逆）
Class: Type 1.5（2-3月可验证，投入时间不可逆）
Acting downside / recovery: 全押3个月且无变现 → 时间损失，recoverable=yes（可降级）
Not-acting permanent loss: 不试 → 永久错过验证"表达类专长能否变现"的窗口
Staging / option-preserving move: 3个月小实验（单一钩子→私信转化率），非无限期日更
Process depth: pilot
Commitment: 跑实验 → 看留资/成交数据 → 再决定加码或降级

---
Decision: 确定毕业职业方向（学术/工业界/交叉/自媒体）
Undo path: 课题可调；退学难逆
Class: Type 1（已含4年不可逆沉没成本）
Acting downside / recovery: 锁定方向后深耕，downside 中，recoverable=partial（课题层可调）

Staging: 当下只锁"读书"这一可逆动作；毕业去向延后至研二

Commitment: 学业立即投入，去向保留选项
```

# 框架四：Pre-Mortem（事前验尸）

**When to Use 检查**：这是高成本、难逆的长期承诺，执行前乐观偏差可能很大 → **适用**。
**When NOT to Use 检查**：非小事、非进行中救火、风险非"通用套话" → 不触发排除。

## 1. Failure Scenario（过去时灾难框架）

> **2029 年 10 月。计划的失败已成定局：** 用户研究生毕业，但**既没在专业方向站住脚，也没能靠自媒体变现**；三年"接触社会"结束，手中的表达技能因长期不投入而退化，因焦虑叠加"考研4年"的沉没感，**又换了一条新赛道从头开始**——这一次仍是零积累。

## 2. Failure Reasons（先发散后筛选，含 S1/S2 专项）

未筛选清单（技术/过程/假设/依赖/人）：
1. 自媒体**始终无变现闭环**，只有内容没有成交。
2. 不知道"每天录什么"→ 内容无钩子 → 招生无留资。
3. 专业方向**始终未确认**，导致投入分散。
4. 「接触社会」计划**停留在设想**，未落到具体动作。
5. 「技能不能停」的诉求与学业时间**直接冲突**，两头都做不透。
6. 交叉标签（双语+医学AI）**从未被真正搭建**。
7. 依赖外部（平台算法、导师课题、招聘市场）**未做预备方案**。
8. 因"证明自己"（假设 S2）而**频繁换赛道**，每次归零。
9. 因考研4年沉没成本 → **不敢放弃也不懂聚焦**，路径依赖。

**优先级（likelihood × impact，保留 Top 5）：**

# 五、四个框架交叉后的共同指向（≤300字小结）

> **四个框架交叉后指向同一处：问题不在"选哪条路"，而在"两条路始终没被接成一条"。**
>
> - **能力圈**发现：用户的表达类专长（双语/讲解/文字）与学历类专长（软工/医学AI）**当前是断裂的**，连接尚无证据。
> - **二阶效应**发现：无论选 A（自媒体）还是 B（专业）单走，都会因无正反馈、沉没成本、心理动因（S2 假设）而衰减或横跳；**只有"交叉标签"能持续产生复利与稀缺性**。
> - **可逆性**发现：自媒体应做**3个月试点**（Type 1.5/2），不能现在 all-in；学业**当下即投入**，毕业去向往后延（Type 1 留选项）。
> - **事前验尸**发现：五条最可能失败路径中，**四条都源于"两线割裂 + 无验证指标"**。
>
> **结论（方向级，非定论）：** 不选"自媒体 or 专业"，而是走**"双语表达 × 专业（医学+AI/软工）"的交叉路径**——用自媒体当**低成本试验场**（3个月拿数据），把专业当**长期护城河**（X周内确认方向）。是否成立，取决于两个待补证据：**①方向确认 ②任意一次真实转化数据**。在此之前，不做不可逆承诺。
