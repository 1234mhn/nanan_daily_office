## 📋 问题清单

### 🔴 问题1：AI 账户余额不足，导致任务停摆（2026-08-19）
- **现象**：派 Claude Code 重做韩语第9课，启动即报错：`Failed to authenticate. API Error: 403 【账户余额不足】当前可用余额 -0.5 元`，请求全发不出。
- **根因**：调用 AI 的 API 账户欠费（余额 ≤ 0），AI 拒绝干活。
- **影响**：项目卡住，用户误以为"任务没做好"，实际是"工具没供上"，烧了约50元还没落成成果。
- **✅ 改动方案**：
  1. 用 AI 前先查账户余额（>0 才能干活），不足先充值再派。
  2. 素材齐全时优先手动完成，不盲目烧 AI 钱。
  3. 大任务开工前先想清完整流程，避免反复试错。

### 🟡 问题2：韩语第9课反复试做未完成（2026-08-18~19）
- **现象**：一整天生成7个 lesson9_backup，但主文件 lesson9.html 始终是「第32课的错误副本」，part1 只完成6句，没拼成完整页。
- **根因**：反复试做每次都停在半路 + 叠加账户欠费，最后没拼完整页。
- **✅ 改动方案**：
  1. 先确认 AI 可用（余额充足）再派，避免白烧钱。
  2. 素材齐全且量不大时手动完成更快更省。
  3. 每完成一个阶段先保存可用的中间成果（part1这种），不推倒重来。
