# 验收统一检查清单

步骤 9 使用。每个检查项只有一个判定口径：`FAIL`（硬错误，必须处理后才能交付）或 `WARN`（应尽量修复，可带警告交付）。同一个问题不允许在不同小节出现不同判定——本文件是唯一口径来源。

## 检查项表

写入 `reports/VERIFY_REPORT.md` 的格式：

```markdown
# 验证和验收报告

## 结论
PASS / FAIL

## 检查项
| 检查项 | 结果 | 说明 |
| --- | --- | --- |

## 返工轮次记录

## EVIDENCE_GAP 核销情况

## 默认采用决策清单      # 无人值守门禁产生的未确认决定

## 仍需处理的问题
```

## 结构与完整性

| 检查项 | 判定 |
| --- | --- |
| 入口文件（main.tex / main.typ / paper.md）或核心正文缺失 | FAIL |
| 入口引用的章节文件不存在、重复引用或未被引用 | FAIL |
| 章节缺一级标题、顺序明显错误 | FAIL |
| 问题集合不一致（题面有而正文没有；摘要提到而正文无模型/结果/结论） | FAIL |
| 模板自带的示例正文、示例数值、示例图表残留 | FAIL |
| 正文出现内部工作流文件名（reports/、figures/、results/、PAPER_CONTENT_PLAN 等）或队号学校等身份信息 | FAIL |

## 内容契约（逐问检查）

| 检查项 | 判定 |
| --- | --- |
| 某问缺模型公式/目标函数、真实结果证据或结果解释段落 | FAIL |
| 某问缺与模型类型匹配的验证证据（见 stage-contracts.md 的表） | FAIL |
| **附录未包含本次运行所用完整源代码（只有命令或文件清单）** | FAIL（提交版唯一口径） |
| `PAPER_CONTENT_PLAN.md` 缺失，或字段不全、证据格未绑定真实文件 | FAIL |
| 存在未核销的 EVIDENCE_GAP 而正文没有对应局限说明 | FAIL |
| 占位符（TODO、待补充、示例数据、XX 等） | FAIL |
| 关键数值与 results/ 或 RESULTS_REPORT 冲突 | FAIL |
| 最终结论/建议型题目缺统一决策汇总表 | FAIL |
| 某问篇幅明显偏少但结构完整、有真实证据 | WARN |
| 图表数量偏少或参考文献偏少 | WARN |

## 图表与排版

| 检查项 | 判定 |
| --- | --- |
| 引用的图片文件不存在、路径错误 | FAIL |
| 编译后 PDF 为空、缺页、页面尺寸异常且无法解释 | FAIL |
| 视觉检查发现重叠、裁切、越界、缺字、乱码 | FAIL |
| caption 偏长；图表后解释不足；连续图表间无过渡文字 | WARN |
| 未引用的备用图片 | WARN |
| 表格非三线表、表题不在表上方、孤立窄横线、窄表被无意义拉伸 | WARN（影响可读性时 FAIL） |
| 同一数据同时以表和图重复表达 | WARN |

## 编译与视觉检查

- Typst：`typst compile`；LaTeX：`xelatex -interaction=nonstopmode` 跑两遍；Word：经 Pandoc 导出后检查 OMML 数量不少于源公式数、无残留 `$...$` 定界符。
- 有视觉能力时，PDF 每页导出 PNG 逐页检查；无视觉能力或渲染工具缺失时，**如实记录"未执行视觉检查"**，并完成 PDF 非空、页数、页面尺寸等程序化检查。禁止把结构验证表述成视觉检查通过。

## CUMCM 提交硬约束

- 电子版从摘要页开始，不含目录、承诺书、编号专用页。
- 摘要（含标题关键词）原则上不超过一页，覆盖每问方法与精确数值。
- 正文不超过比赛当年官方页数上限；页数/表数/图数只用于发现失衡，不设最低配额。
- 全文不得出现学校、赛区、队号、队员姓名。
- 附录包含完整可运行的本次源代码（FAIL 口径见内容契约表，此处不重复判定）。

## PASS 条件

所有 FAIL 项清零、EVIDENCE_GAP 全部核销或显式降级、编译通过（或明确记录不可编译原因）、视觉检查通过或如实记录未执行、无人值守默认决定已列入清单。此时才写 `PASS`。
