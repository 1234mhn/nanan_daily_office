# 跨赛事通用规范性审查清单

本清单适用于所有数学建模竞赛论文。赛事专属条款（承诺书、编号页、页数、页眉等）见 `cumcm_standards.md` 与 `mcm_icm_standards.md`，本文件只处理与赛事无关的写作与技术规范。

## 一、摘要审查

摘要是评阅权重最高的部分，全国评阅首先依据摘要与论文整体结构进行初步筛选。必须逐项核对。

### 国赛摘要（详细摘要）必备要素

| 要素 | 检查内容 |
|------|----------|
| 问题背景与任务 | 一两句话说明研究对象与要解决的问题，不照抄题面 |
| 模型的数学归类 | 明确说明模型在数学上属于什么类型（如优化模型、微分方程模型、图论模型、统计回归模型） |
| 建模思想与思路 | 说明为何这样建模，关键假设与简化依据 |
| 算法与求解思路 | 说明计算方法、算法名称、软件与版本 |
| 主要结果 | **必须给出数值结果**，且回答题目所问的每一个问题 |
| 检验与结论 | 说明误差分析、灵敏度分析、稳定性分析或对比验证的结论 |
| 模型特点 | 简要点明创新之处或方法优势 |
| 关键词 | 3 至 5 个，覆盖核心模型与方法，不与方法无关 |

国赛摘要常见问题：仅有文字描述而无任何数值结果；夸大其词或过度自谦；篇幅超过一页；关键词数量不当或与正文无关；未回答题目全部问题。

### 美赛摘要（Summary Sheet）必备要素

| 要素 | 检查内容 |
|------|----------|
| 位置与篇幅 | 第一页，独立一页，计入 25 页 |
| 问题重述 | 用团队自己的语言简述问题，非复制题面 |
| 方法与模型 | 说明所用模型与选择理由 |
| 主要结论与数值 | 明确给出关键数值结果与结论 |
| 关键词 | Keywords 字段完整 |

美赛摘要的硬性负面清单：仅重述竞赛题目；直接从 Introduction 剪切粘贴；无数值结果；未突出最重要的结论。

## 二、标题审查

- 标题是否准确反映研究内容，避免过大过空的泛化表述。
- 标题是否包含具体方法或对象，便于评阅人快速归类。
- 标题长度适中，国赛一般不超过 20 字，美赛英文标题一般 8 至 15 词。
- 标题中不应出现学校名、队名、赞助商名、人名。
- 标题与正文末结论是否呼应，避免文题不符。

## 三、章节结构审查

标准结构（国赛与美赛通用，名称可调整）：

1. 摘要与关键词
2. 问题重述（或 Introduction）
3. 问题分析（可选，国赛常并入问题重述）
4. 模型假设与符号说明
5. 模型建立
6. 模型求解与算法设计
7. 结果分析与检验（含误差分析、灵敏度分析）
8. 模型评价与改进（优点、缺点、推广）
9. 结论
10. 参考文献
11. 附录

结构审查的具体判据：

- 章节编号是否连续，层级是否超过三级。
- 是否存在有标题无实质内容的空节。
- 各节篇幅是否失衡，避免某一节占全文一半以上。
- 问题重述是否逐条对应题目所问，后续章节是否逐条给出回答。
- 符号说明表是否置于模型建立之前。
- 结论是否是新的概括，而非各节摘要的简单拼接。
- 模型评价是否客观，是否同时给出优点与缺点。
- 是否存在把推导、代码、长表错误地塞进正文的情况。

## 四、图表审查

### 编号

- 图表编号体系是否统一：按章编号（图 3-2、表 4-1）或全文连续编号（Figure 5、Table 2），不得混用。
- 编号是否连续，无重复、无跳跃、无缺号。
- 附录图表编号是否与正文体系区分（如 附图 A-1、Table A1）。

### 标题与标注

- 每个图与表必须有编号与标题；国赛图题在下、表题在上。
- 坐标轴有名称与单位，刻度值清晰。
- 多系列图有图例，图例与数据对应无误。
- 表格推荐使用三线表，数值右对齐或小数点对齐。
- 表中数据注明单位，避免每格重复单位符号。

### 正文引用

- 每个图表必须在正文中被明确引用，不得插入后不提。
- 正文中引用的编号与实际图表编号一致，这是最高频的错漏点。
- 引用句式规范，如 由图 3 可知、As shown in Figure 2。
- 图表与引用之间不跨过远，避免相距数页。

### 来源与质量

- 引用他人图表或数据必须标注来源。
- 图片分辨率足够，打印后清晰可辨，避免位图拉伸。
- 避免过度彩色打印，国赛规范建议必要的彩色图形图表除外。
- 图表中的数值与正文描述一致，与支撑材料中的输出一致。

## 五、公式与符号审查

- 关键公式必须编号，编号体系统一且连续。
- 重要结论式、目标函数、约束条件均应有编号。
- 每个符号在首次出现处给出定义与单位。
- 符号表完整，覆盖全文出现的全部符号，无遗漏。
- 同一符号在全文只表示一个含义，不同含义不得复用。
- 正体与斜体使用规范：变量与参数用斜体，常量、单位、函数名与微分符号用正体。
- 上下标层级清晰，求和与积分的上下限完整。
- 公式与正文之间有必要的说明文字，不出现孤立的公式堆砌。
- 不得使用截图形式的公式，必须可编辑排版。
- 量纲一致，等式两边量纲可检验。
- 向量与矩阵有明确的字体或记号约定并在符号表中说明。

## 六、附录审查

- 附录内容是否完整：源程序、软件名称与版本、命令行、自主采集的数据、大篇幅中间结果、长表格、补充推导。
- 源程序是否可运行，是否与论文报告的结果一致。
- 程序中是否含有身份信息（路径名、用户名、学校邮箱）。
- 赛题提供的原始数据不应进入附录（国赛第五条）。
- 附录是否被正文引用，避免附录与正文脱节。
- 附录编号是否与正文体系区分。
- 关键参数与随机种子是否在附录中给出，保证结果可复现。

## 七、数据与结果自洽性审查

- 正文中报告的数值与图表、附录、支撑材料中的输出是否一致。
- 有效数字位数是否合理，避免 6 位以上无意义小数或过度舍入。
- 随机化算法是否说明随机种子与重复次数。
- 是否存在未标注来源的数据。
- 是否存在明显违背常识或量纲错误的结果。
- 是否有结果检验，包括误差分析、灵敏度分析、稳定性分析或与其他方法的对比。
- 多问题目是否逐问给出结果，是否存在遗漏未答的小问。

## 八、语言与表述审查

- 术语全文统一，避免同义词混用。
- 避免使用第一人称复数过度自夸的表述。
- 避免口语化、口号化、无信息量的填充句。
- 长句是否可读，是否存在成分残缺。
- 英文论文检查语法、冠词、单复数与时态。
- 是否存在抄袭痕迹，包括与他人论文高度相似的段落。
- 是否出现致谢、签名、日期、单位署名等身份暴露内容。

## 九、通用红线（一律判定为严重问题）

1. 正文或附录泄露参赛者、指导教师、学校、赛区身份。
2. 源程序缺失、不能运行或与论文结果不符。
3. 数据或结果存在伪造、篡改、无法复现的迹象。
4. 参考文献中存在虚构条目。
5. 大段文字与他人已发表作品高度相似且未引用。
6. 使用 AI 生成内容而未按规定披露。
7. 页数、文件命名、文件格式等硬性提交要求不满足。
