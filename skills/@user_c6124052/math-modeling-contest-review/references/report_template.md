# 结构化审核报告模板

## 一、严重程度三级定义

| 级别 | 定义 | 处置要求 |
|------|------|----------|
| 严重问题 | 触及参赛资格、匿名性、承诺书与编号页、页数与文件规范、源程序与支撑材料、数据真实性、虚构文献 | 提交前必须整改，未整改不得参赛 |
| 一般问题 | 影响评阅得分与专业观感，包括摘要缺要素、图表编号错乱、公式无编号、符号不一致、结构失衡、文献信息有误 | 应当整改 |
| 修改建议 | 不影响资格与主要得分的优化项，包括措辞精炼、图示增强、对比实验补充、灵敏度分析加强 | 可选择性采纳 |

定级纪律：不得因论文整体质量高而下调严重问题的级别，也不得因格式瑕疵众多而把一般问题升级为严重问题。定级依据是后果，不是数量。

## 二、报告骨架

```
# 数学建模竞赛论文审核报告

## 0. 基本信息与审核范围
## 1. 竞赛类型判定
## 2. 总评与风险等级
## 3. 严重问题（N 项）
## 4. 一般问题（N 项）
## 5. 修改建议（N 项）
## 6. 参考文献核查（N 条）
## 7. 提交前必办清单
```

## 三、各段写法

### 0. 基本信息与审核范围

以表格给出：文件名、赛事、组别与题号、总页数、正文页数、附录页数、字数、支撑材料清单、审核项目（全项 / 仅格式 / 仅文献）、审核范围限制说明。

范围受限时必须显式声明。示例：仅收到论文正文 PDF，未收到支撑材料与源程序，附录相关条目列为待补材料。

### 1. 竞赛类型判定

复述判定结论与依据，格式见 `contest_identification.md` 的输出格式一节。若存在信号冲突，在此说明处置方式。

### 2. 总评与风险等级

150 至 250 字，包含选题与建模思路概述、主要优点、主要不足、风险等级。风险等级三选一：

- 可直接提交：无严重问题，一般问题不超过 5 项。
- 需修改后提交：存在严重问题但均可整改，或一般问题较多。
- 存在取消资格风险：出现身份泄露、承诺书缺失、支撑材料不符、数据存疑或虚构文献等，且整改窗口不足。

### 3 至 5. 三级问题表

三级各一张表，列固定如下：

| 列 | 内容要求 |
|----|----------|
| 编号 | 严重问题用 S1、S2；一般问题用 M1、M2；修改建议用 A1、A2 |
| 位置 | 精确到页、节、图号、表号或公式号。禁止使用 某处、部分、若干 一类模糊指代 |
| 问题描述 | 客观陈述观察到的事实，不加主观评价 |
| 原因说明 | 解释为什么这是问题，以及不整改的后果 |
| 依据条款 | 写明出处，如 国赛论文格式规范第三条、MCM/ICM 2027 规则 Preparing 第 3 条、通用清单第四章 |
| 改进建议 | 可执行的动作，给出具体做法或改写示例 |

### 6. 参考文献核查表

列固定为 编号 / 著录原文 / 检索源 / 核验结论 / 冲突字段 / 处置建议。
结论取值限定为 真实、信息有误、高度可疑、无法核实。
另起一段给出汇总：共 N 条，真实 X 条，信息有误 Y 条，高度可疑 Z 条，无法核实 W 条。
再起一段说明引用对应关系核查结果。

### 7. 提交前必办清单

按优先级排序，控制在 10 条以内，每条为一个可勾选的动作。示例：

1. 删除正文第 12 页致谢段中的学校名称，消除身份泄露风险。
2. 将电子版第一页承诺书移除，使第一页为摘要页。
3. 补录附录中的 Python 源程序，并确认可运行。
4. 替换参考文献 [3]，或提供原文首页佐证。
5. 修正图 4-2 与正文引用编号不一致的问题。

## 四、批量审核汇总表

一次审核多篇时，在全部单篇报告之前给出汇总表：

| 序号 | 队号或文件名 | 赛事与题号 | 严重问题数 | 一般问题数 | 风险等级 | 首要整改项 |
|------|--------------|------------|------------|------------|----------|------------|

## 五、写作禁忌

- 禁止只给总体评价而不列具体条目。
- 禁止使用模糊位置指代。
- 禁止只指出问题不给改进建议。
- 禁止把未能核实写成已核实，或把未能核实写成造假。
- 禁止在同一条目中混入多个独立问题，应拆分为多条。
- 禁止引用不存在的规范条款，不确定条款归属时写 通用规范 并说明判断依据。
