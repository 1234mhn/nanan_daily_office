# 竞赛类型自动识别

## 识别原则

识别必须在规范性审查之前完成。识别错误会导致整份审核报告的依据条款失效，例如把美赛的目录要求判给国赛，或把国赛的承诺书要求判给美赛。

识别采用三级证据，按可靠性从高到低排列：

| 级别 | 证据类型 | 说明 |
|------|----------|------|
| 一级 | 显式标识 | 承诺书、编号专用页、Team Control Number 页眉、Summary Sheet 模板页、AI Use Report 标题、赛题编号 |
| 二级 | 语言与版式 | 正文主体语言、页眉页脚形态、装订方式、字体字号体系 |
| 三级 | 章节结构 | 是否含目录、摘要所在页码、章节命名习惯 |

一级证据存在时直接定案。只有二三级证据时必须向用户确认。

## 信号对照表

| 信号 | 指向 CUMCM 国赛 | 指向 MCM/ICM 美赛 |
|------|-----------------|-------------------|
| 第一页内容 | 承诺书（含 我们仔细阅读了…竞赛规则 字样） | Summary Sheet（含 Summary、Keywords 字样与控制号） |
| 第二页内容 | 编号专用页（赛区评阅编号、全国统一编号栏） | 正文或目录延续 |
| 页眉 | 规范要求不得有页眉 | 每页必须有 `Team # xxxxxxx, Page X of 25` |
| 页码位置 | 页脚中部，从摘要页起第 1 页 | 页眉内，与 Team # 同行 |
| 正文语言 | 中文 | 英文，12 号及以上字体 |
| 目录 | 明确要求不要目录 | 鼓励使用目录且计入页数 |
| 题目编号 | A/B（本科组）、C/D（专科组） | A/B/C（MCM）、D/E/F（ICM） |
| 页数约束 | 正文 20 页以内，附录不限 | 全部内容 25 页以内，附录计入 |
| 程序处理 | 附录打印源程序 + 支撑材料 RAR 单独提交 | 代码可入附录计入页数，不得单独随附文件 |
| AI 披露 | 无统一要求（以当年通知为准） | 必须用行内引用 + `Report on Use of AI` |

## 组别判定（国赛）

- 本科组选 A 或 B 题，专科组选 C 或 D 题。
- 承诺书上的 我们参赛选择的题号是（从 A/B/C/D 中选择一项填写） 一栏是组别判定的直接依据。
- 若题号与组别不匹配（本科生做 C/D 题），按当年竞赛章程处理，需在报告中提示用户核对。

## 美赛 MCM 与 ICM 的区分

| 题号 | 归属 | 常见题材 |
|------|------|----------|
| A | MCM | 连续型、物理与工程背景 |
| B | MCM | 离散型、运筹与网络 |
| C | MCM | 数据驱动、大数据与统计分析 |
| D | ICM | 运筹学、网络科学、系统科学 |
| E | ICM | 环境科学、可持续发展、政策 |
| F | ICM | 社会科学、政策建模、人文议题 |

MCM 与 ICM 共用同一套格式规则，区分的意义在于**模型评价口径**：MCM 侧重数学方法的严谨与求解质量，ICM 侧重跨学科建模的合理性、数据支撑与政策含义。审核模型章节时据此调整评价重心。

## 冲突与误判处置

出现以下情形时停止自动判定，向用户提问：

1. 中文正文但含 Team # 页眉，或英文正文但含中文承诺书。
2. 同时存在承诺书与 Summary Sheet。
3. 无任何页码、页眉、承诺书等可识别标识。
4. 用户明确表示是校赛、省赛、数维杯、电工杯、华为杯研究生赛等其它赛事。

其它赛事的处理路径：向用户索取该赛事官方格式规范的原文或链接，将其条款整理为临时检查表后执行审核，并在报告中标注依据来源为 赛事官方规范 而非本 skill 内置条款。禁止用国赛或美赛条款强行判罚其它赛事。

## 输出格式

识别完成后向用户复述一段判定说明，示例：

> 判定结果：全国大学生数学建模竞赛（CUMCM）本科组 B 题。依据：第一页为承诺书且题号栏填 B；第二页为编号专用页；第三页起为摘要与正文；全文中文且无页眉；无 Team # 标识。将按 2023 年修订的《全国大学生数学建模竞赛论文格式规范》执行审查。

待用户确认后进入规范性审查。若用户未回复而材料信号明确，可直接继续，但在报告中保留判定依据段落。
