# 数学建模竞赛论文审核 Skill

## 定位与身份

使用本 skill 时，用户身份为**数学建模竞赛指导教师或赛区评阅人**，提交物为一篇（或一批）学生的数学建模竞赛论文。审核目标是**赛前定稿把关**：在提交截止前把会导致退赛、降档或取消评奖资格的硬伤找出来，并给出可执行的修改清单。

本 skill 与毕业论文指导类技能的分工不同，必须区分：

- 毕业论文审核关注学术规范、原创性与答辩口径，允许长周期返修。
- 竞赛论文审核关注**格式合规与评阅适配**，返修窗口极短，且部分瑕疵直接导致取消资格（身份泄露、承诺书缺失、程序不可运行、支撑材料不符）。

因此本 skill 的第一原则是**合规优先于文采**。凡是涉及参赛资格、匿名性、页数、承诺书、源程序与支撑材料的问题，一律归入最高严重程度，先解决再谈模型。

## 规范依据文件

评阅与核验的权威来源按需调取 `references/` 下六个文件：

- `references/contest_identification.md`，竞赛类型自动识别信号表与误判处置
- `references/cumcm_standards.md`，全国赛论文格式规范（2023 年修订稿）条款原文要点、承诺书与编号专用页样式、评阅四标准
- `references/mcm_icm_standards.md`，MCM/ICM 规则要点、Summary Sheet 要求、AI Use Report 要求、评审等级与评委关注要素
- `references/common_checks.md`，跨赛事通用审查清单（摘要、标题、章节结构、图表编号与引用、公式排版、附录、术语与符号一致性）
- `references/reference_verification.md`，参考文献真实性核查流程、检索源优先级、可疑等级判定与典型造假特征
- `references/report_template.md`，结构化审核报告模板与三级分级定义
- `references/worked_example.md`，一份完整的国赛论文审核报告范例，用于校准条目颗粒度、严重程度定级与文字风格。输出报告前必读

辅助工具：

- `scripts/scan_paper.py`，机械扫描脚本，输出页数与页数合规性、美赛 Team # 页眉校验、图表标题与正文引用一致性、公式编号连续性、正文引用与文献表差集、疑似身份泄露、DOI 与 ISBN 校验位等客观指标。人工判断不得被脚本替代，脚本只提供待核项。
- `scripts/make_sample_pdf.py`，生成含已知缺陷的虚构论文，用于脚本回归测试。依赖 reportlab。

## 工作流程（五阶段）

### 阶段 0：接收与预处理

1. 确认输入文件（PDF 优先，Word 次之）与用户的审核诉求：全项审核 / 仅查格式 / 仅查文献 / 出具定稿意见。
2. 若文件超过 30 页或批量多篇，先运行 `scripts/scan_paper.py` 取得客观指标，再进入人工判读。
3. 若用户只给了正文而无附录、无支撑材料，须在报告开头声明审核范围受限，并将附录与支撑材料相关条目列为**待补材料**，不得跳过。
4. **Word 稿的特殊处理**。docx 为流式格式，脚本按显式分页符切分为近似页，页数不可靠。凡涉及页数、页码、页眉页脚的判据（国赛正文 20 页、美赛 25 页、页眉要求）均须在导出 PDF 后复核，报告中须明示该限制。docx 的页眉页脚可从节属性直接读取，国赛要求不得有页眉，非空即违规。

运行环境：`C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Scripts\python.exe`。
依赖缺失时执行 `pip install pypdf pdfplumber`；脚本读取 PDF 文本，扫描版 PDF（图片型）将返回空文本，此时改用人工翻阅并在报告中注明。

### 阶段 1：竞赛类型自动识别（必做，先于一切审查）

依据 `references/contest_identification.md` 的信号表判定赛事，判定依据按优先级：

1. 显式信号：承诺书、编号专用页、Team Control Number 页眉、Summary Sheet、AI Use Report、题号（A/B/C/D 对国赛，A–F 对美赛）。
2. 语言信号：中文正文且含承诺书指向国赛；英文正文且含 Team # 页眉指向美赛。
3. 结构信号：无目录 + 摘要专用页在第三页指向国赛；目录 + 摘要在第一页指向美赛。

识别后**立即向用户复述判定结论与依据**（赛事、组别、年份、题号），确认后再进入阶段 2。若信号冲突或不足以判定，直接询问用户，禁止凭猜测套用标准。

已支持的赛事与扩展规则：

| 赛事 | 识别关键 | 采用标准 |
|------|----------|----------|
| CUMCM 全国大学生数学建模竞赛（本科组 A/B、专科组 C/D） | 承诺书 + 编号专用页 + 中文 | `cumcm_standards.md` |
| MCM/ICM 美国大学生数学建模竞赛（A–F 题） | Summary Sheet + Team # 页眉 + 英文 | `mcm_icm_standards.md` |
| 其它赛事（数维杯、华为杯研究生赛、电工杯、校赛等） | 无上述信号 | 通用清单 + 用户提供的该赛事官方规范 |

遇到未在表中的赛事，索取官方格式规范原文后再审核，禁止套用国赛或美赛条款强行判罚。

### 阶段 2：规范性审查

按识别结果加载对应标准文件，逐项打勾。**逐项列出不符合项，不得只给总体评价。**

国赛审查要点（详见 `cumcm_standards.md`）：

1. 承诺书与编号专用页：存在性、位置（第一页、第二页）、填写完整性（题号、报名号、学校全称、队员与指导教师签名、日期）、编号栏不得由参赛队填写。
2. 摘要专用页独立性：题目、摘要、关键词在第三页，单独成页，不超一页，无需英文翻译。
3. 页码：从第三页起编，页脚中部，阿拉伯数字从 1 连续。
4. 匿名性：正文与附录不得出现姓名、学号、校名、校徽、赛区、指导教师、致谢对象；不得有页眉。
5. 正文篇幅控制在 20 页以内，附录页数不限。
6. 附录须含可运行源程序、软件名称与命令、自主查阅的数据；赛题原始数据不入附录。
7. 电子版与纸质版一致性，电子版不含承诺书与编号页，单文件 PDF 或 Word，不压缩，不超过 20MB。
8. 支撑材料：RAR 压缩包，含全部源程序与自采数据，不超过 20MB；程序不能运行或结果与论文不一致可致取消评奖资格。

美赛审查要点（详见 `mcm_icm_standards.md`）：

1. 总页数不超过 25 页，含 Summary Sheet、目录、参考文献、附录、代码，AI Use Report 不计入。
2. 每页页眉为 `Team # 控制号, Page X of 25` 格式，字体不小于 12 号。
3. Summary Sheet 位于第一页，为独立一页，须包含方法、模型与核心结论，禁止复述题面或照搬引言。
4. 使用 AI 工具必须有行内引用、参考文献条目，且在 25 页之后附加 `Report on Use of AI`。
5. 全程匿名，除控制号外无任何身份信息。
6. 文件名以控制号命名，PDF 小于 25MB，不随附数据或程序文件。

通用审查要点（详见 `common_checks.md`）：摘要要素完整性、题名与内容匹配、章节结构完整性与比例、图表编号与正文引用一致性、图表标题与单位、公式编号与变量说明、符号表与全文符号一致性、术语统一、量纲与有效数字、参考文献在正文中的引用覆盖。

### 阶段 3：文献真实性核查

按 `references/reference_verification.md` 执行，**逐条核验，不抽样**。对每条文献至少完成一次外部检索，检索源优先级：DOI 解析、Crossref、Web of Science、Scopus、MathSciNet、zbMATH、Google Scholar、期刊官网、出版社官网、知网、万方、维普；中文图书核对 CIP 与出版社目录，英文图书核对出版社页面与 WorldCat。

核验维度：题名、作者、期刊或出版社、年份、卷期与起止页、DOI 是否解析到同一记录。

判定结论分四档：真实、信息有误、高度可疑、无法核实。后三档必须在报告中列出证据（检索式、返回为空的源、字段冲突之处）。

同时核查引用对应关系：正文引用编号与文献表一一对应、无未列文献的引用、无未被引用的堆砌文献、转引标注原文献、网络资源有访问日期、AI 工具有引用条目。

### 阶段 4：输出结构化审核报告

严格套用 `references/report_template.md`，包含六部分：

1. 论文基本信息与审核范围（赛事、组别、题号、页数、字数、文件清单、审核范围限制说明）。
2. 总评与风险等级（可直接提交 / 需修改后提交 / 存在取消资格风险）。
3. 严重问题表（逐条：编号、位置、问题描述、违反条款、后果、整改要求）。
4. 一般问题表（同上，后果较轻）。
5. 修改建议表（优化项，不影响资格）。
6. 参考文献核查表（逐条列出核验结论与证据）。

严重程度分级定义（不得自行放宽或加严）：

- **严重问题**：触及参赛资格、匿名性、承诺书、页数、源程序与支撑材料、数据真实性、虚构文献。此类问题不解决将导致退赛、无效或取消评奖资格。必须在提交前整改。
- **一般问题**：影响评阅得分与专业观感，如摘要缺要素、图表编号错乱、公式无编号、符号前后不一致、结构失衡。应整改。
- **修改建议**：锦上添花的优化项，如措辞精炼、图示增强、对比实验补充、灵敏度分析加强。可选择性采纳。

## 输出约定

- 报告用 Markdown，三级问题各一张表，表格列固定为 位置 / 问题描述 / 原因说明 / 依据条款 / 改进建议。
- 位置须精确到页、节、图号、表号或公式号，禁止使用 某处、部分地方 一类模糊指代。
- 每条问题必须给出可执行的改进建议，禁止只指出问题不给方案。
- 引用规范条款时写明出处（如 国赛论文格式规范第三条、MCM/ICM 2027 规则 Preparing 第 3 条）。
- 文献核验结论须区分 已核实 与 未能核实，禁止把检索不到直接等同于造假，也禁止把检索不到放过不报。
- 报告结尾给出**提交前必办清单**，按优先级排序，控制在 10 条以内。

## 年度校验义务（强制）

竞赛规则逐年调整（页数、提交方式、AI 政策均发生过变更）。每次审核开始前，若距上次核实该赛事规则超过 6 个月，或用户论文所属年份与已知规则年份不一致，必须先用 WebFetch 拉取当年官方规则页核对关键条款，再执行审查。

官方规则入口：

- 全国赛：https://www.mcm.edu.cn/
- 美赛：https://www.contest.comap.com/undergraduate/contests/mcm/instructions.php

若发现本 skill 记录的条款与官方现行条款冲突，**以官方为准**，并在报告中标注该差异，随后修正 `references/` 对应文件。
