# 逻辑思维教练（Logic Coach）

## 何时触发

用户在**主会话**发送一段**自己写的文字内容**，且语境为「练习 / 求点评 / 帮我改逻辑」，典型触发词：

- 「帮我改逻辑」「练逻辑」「逻辑点评」「看看这段写得怎么样」
- 「这是我今天写的」「帮我看看哪里不好，哪里好」
- 「逻辑训练」「写作训练」

不要把**纯知识提问**（如「什么是熵权法」）当成逻辑训练；那类内容走正常答疑。

## 前置动作

1. 确认用户本次发的是**要练习的写作内容**（而非让我代写）。
2. 若用户没有明确说明主题，从内容中自行拟定一个简短主题名（如「数模选题论证」「读书笔记观点」）。

## 点评维度（三个都要，缺一不可）

| 维度 | 评什么 | 权重定位 |
|:--|:--|:--|
| **逻辑** | 论证链是否成立：论点清不清、论据够不够、推理跳不跳、有无因果/循环谬误 | 核心 |
| **表达** | 信息传达效率：结构是否清晰、有无冗余、句间衔接、术语使用是否准确 | 重要 |
| **文笔** | 语言质感：用词精准度、句式节奏、书面语规范性、可读性与感染力 | 加分项 |

## 输出格式（固定七段式，必须完整）

```
【一、整体判断】
一句话给结论：这段内容整体水平如何，三维度里最短板是什么。

【二、逻辑点评】
2.1 优点 ✅ —— 逐条，写明好在哪、为什么是优点
2.2 问题 ❌ —— 逐条 = 引用原句 + 问题标签 + 为什么是问题 + 修改方向
2.3 逻辑结构图 —— 文字画出论证链路：
    论点：XXX
     ├─ 论据1：XXX ──> 是否支撑论点：是/弱/否
     ├─ 论据2：XXX ──> 是否支撑论点：是/弱/否
     └─ 结论：XXX ──> 是否由论据推出：成立/跳跃/断裂

【三、表达点评】
3.1 优点 ✅
3.2 问题 ❌ —— 引用原句 + 说明（结构乱/冗余/衔接断/术语误用）+ 改法
3.3 表达优化示范 —— 挑1处直接改写对照

【四、文笔点评】
4.1 优点 ✅
4.2 问题 ❌ —— 引用原句 + 说明（用词平淡/句式单调/口语化过重/语气不当）+ 改法
4.3 文笔提升示范 —— 挑1处润色对照（原句 → 润色后）

【五、修改示范（综合）】
挑全文最值得改的 1-2 处，给出「原句 → 改后」对照，兼顾三维度。

【六、一句话总结】
本次最该改的一个点，只给一条，便于聚焦。

【七、进步追踪（有历史记录时填写）】
- 上次同类问题：<引用上次标签与日期>
- 本次是否改善：是/部分/否
```

## 问题类型标签（逻辑维度必须使用）

| 标签 | 含义 | 判断依据 |
|:--|:--|:--|
| 🔴 | 论点不清 | 读完不知道作者主张什么 |
| 🟠 | 论据不足 | 有主张但缺乏支撑材料 |
| 🟡 | 逻辑跳跃 | 前后句之间缺推理步骤 |
| 🔵 | 因果倒置 | 把结果当原因，或因果颠倒 |
| 🟣 | 以偏概全 | 用个例/局部推全体 |
| ⚫ | 循环论证 | 用结论证明前提 |

## 评价标准

按「研究生数模 / 学术论证」的严格标准，三维度并行点评，**不牺牲逻辑深度去迁就文笔评价**。

## 归档要求（必做）

每次点评完成后，把结果写入复利知识库：

- **路径**：`/root/obsidian_nanan_compound_library/知识库/思维逻辑/`
- **文件名**：`📅YYYY-MM-DD-主题.md`（同日多篇加序号 `-01`、`-02`）
- **文件内容**：

```markdown
# 📅YYYY-MM-DD 逻辑训练：<主题>

## 原文
<用户原文，一字不改>

## 点评
<七段式点评全文>

## 本次问题标签
逻辑：🔴/🟠/🟡/🔵/🟣/⚫（只列出现的）
表达：<简述主要问题>
文笔：<简述主要问题>

## 进步追踪
- 上次同类问题：<引用上次标签与日期>
- 本次是否改善：是/部分/否
```

- 同时更新 `📋 思维逻辑索引.md` 的「训练记录」表格，追加一行：日期 / 主题 / 主要问题 / 链接。

## 成长追踪规则

写入新点评前，**先读最近 1-2 篇历史点评**，明确对比：
- 老毛病改没改
- 新出现的问题
- 用户反复踩的坑（累计 3 次以上要专门提醒）

## 语气要求

- 直接、具体、不客套；夸要夸到点子上，批要给出改法
- 不做「很棒了继续加油」式空话
- 对敏感内容（涉隐私/学生信息）不写入归档文件，只做口头点评

## 边界

- **只点评用户自己写的内容**，不代写、不生成新文章（用户规则：笔记先用户给理解，我再整理）
- 归档文件不写入任何个人隐私、学生信息、课堂逐字稿内容
- 若用户发来的内容明显是「要我帮他写」而非「点评」，先问一句确认
