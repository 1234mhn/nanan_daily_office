# 问题一解题思路流程图（v2 分支版）

## 用途
《算力约束下提升大语言模型能力的资源配置建模》（华为杯研赛 F 题）**问题一**的解题思路**严格流程图**。
用于直接插入论文正文（含判断菱形框与"是/否"分支、两支汇合）。

## 文件清单
| 文件 | 说明 |
|:--|:--|
| `q1_flowchart_v2.svg` | 自包含 SVG 源文件（矢量，可无损缩放） |
| `q1_flowchart_v2.png` | 位图导出（3000×5700 px，约 300dpi 等效） |
| `q1_flowchart_v2.drawio` | mxGraph XML，可在 draw.io / 飞书白板 打开继续编辑 |
| `README.md` | 本说明 |

## 图形规范（已执行）
- 画布 1000×1900 px，竖版；白底 + 深灰边框 `#4A4A4A`（1.7px）+ 黑字
- 「开始 / 结束」= 圆角胶囊（浅灰底 `#F2F2F2`）
- 普通步骤 = 直角矩形（白底）
- 「c_s ≥ δ（90%分位数）?」= **菱形判断框**
- 分支：菱形右下引「是」支、左下引「否」支，两支汇合于同一汇合点后进入「输出质量评分、冲突标记结果」
- 无渐变 / 阴影 / 3D / emoji / 装饰
- 字体 `Noto Sans CJK SC`（回退 DejaVu Sans），正文 14.5px

## 如何改字（三种方式，任选）
1. **改 SVG（推荐，最精确）**：用文本编辑器打开 `q1_flowchart_v2.svg`，搜索要改的文字（如 `组内取中位数`），直接替换 `<text>` 标签内容即可。文字居中，`x` 为框中心、`y` 为基线。
   - 改完重新导出 PNG：
     ```bash
     cairosvg q1_flowchart_v2.svg -o q1_flowchart_v2.png -W 3000 -H 5700
     ```
2. **改 drawio**：在 draw.io 打开 `q1_flowchart_v2.drawio`，双击节点改字，再导出 PNG/SVG/PDF。
3. **换图注编号**：把 SVG 中 `图 X  问题一解题思路流程图` 的 `X` 改成实际图号。
