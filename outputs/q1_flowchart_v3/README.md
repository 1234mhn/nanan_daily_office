## 图形规格

- 画布：1000 × 1342（SVG 单位），内容自适应高度，无大片空白
- 边框：`#3D3D3D`，线宽 1.6 px；文字纯黑
- 字体：`Noto Sans CJK SC`（回退 `DejaVu Sans`），正文 14.5 px，图注 16 px
- 布局：顶部单列（开始 → 数据读取 → 预处理 …）→ 菱形判断分叉为左右两列 → 合流 →
  再次分叉为两个模型框 → 合流 → 单列收尾 → 结束
- 图注居中于底部：「图 X  问题一解题思路流程图」（**X 号请按论文实际编号手动替换**）

## 结构要点

1. 第 7 步菱形判断框 `c_s ≥ δ (90%分位数)`：**右侧引出「是」支**（计算稳健秩评分 S_s*、标记冲突样本），
   **左侧引出「否」支**（直接使用综合评分 S_s），两支各自向下后水平连回主线合流。
2. 第 10 步两个模型（和约束线性岭回归 / 二阶交互岭回归）用左右并列两框，
   同样按「分叉 → 水平线 → 两列各自下排 → 合流」画法。
3. 「开始」「结束」均为直角矩形（与参考图一致，非胶囊形）。

## 如何改字

- **小改**：直接编辑 `q1_flowchart_v3.svg`，找到对应 `<text>…</text>`，替换文字即可。
  注意框宽是固定的；若文字变长，请同步调大该 `<rect>` 的 `width`（并保持居中的 `x`）。
- **推荐改法**：编辑 `gen_svg.py` 里的节点文本（如 `n = ["…"]`），然后重跑：
  ```
  python3 gen_svg.py                 # 重新生成 SVG
  cairosvg q1_flowchart_v3.svg -o q1_flowchart_v3.png --output-width 2400
  # 若需纯灰度：渲染后用 PIL 转 L 模式再保存
  python3 gen_drawio.py              # 重新生成 drawio
  ```
- 长句换行：在文本里用两行（`["前半句、", "后半句"]`）手动断行，保证不溢出边框。
