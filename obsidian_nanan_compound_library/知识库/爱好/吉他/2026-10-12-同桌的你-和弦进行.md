# 🎸 《同桌的你》和弦进行（音艺吉他 C调弹唱版）

> 老狼 · 高晓松词曲 · 1994 · 校园民谣
> 谱源：iloveguitar.cn/tab/643.html（图片谱 2 张）

---

## 一、全曲用到的和弦

**C调常用：** `C` `Dm7` `Em` `F6`（=F）`G` `G7` `Am`

**转调段额外出现（后半段升 D 调）：** `Bm` `#Fm` `A` `A7`

> 📌 谱上写 `Am(Bm)` `Em(#Fm)` `G(A)` `G7(A7)` 这种带括号的，意思是：
> **C调段弹括号外，转D调那段弹括号里**（同一套指型整体上移，不用换谱）。

---

## 二、分段和弦进行

### 🎸 主歌（"明天你是否会想起…"）

核心循环（基本重复两遍）：

```
F6 → C → Em → F6 → G → C
```

- 明天你是否会想起 = F6
- 昨天你写的日记 = C
- 明天你是否还惦记 = Em
- 推进句 = F6 → G → C

### 🎤 副歌（"谁娶了多愁善感的你…"）— 低音下行

```
C → Dm7 → Am → Em → F6 → G7 → C
```

- 谁娶了多愁善感的你 = C
- 谁安慰爱哭的你 = Dm7 → Am
- 谁把你的长发盘起 = Em → F6
- 谁给你做的嫁衣 = G7 → C

### 🎼 间奏 / 尾奏（第2页）

```
G → G7 → C → Am(Bm) → A → B → D.S.
Dm(Em) → Am(Bm) → Em(#Fm) → G(A) → G7(A7)
```

（D.S. = 从头反复记号，弹完回开头再走一遍）

## 三、🔁 重复的和弦 —— 记 3 个套路弹全曲

| 套路 | 进行 | 用在哪 |
|:--|:--|:--|
| ① 主歌循环 ⭐最多 | `F6 → C → Em → F6 → G → C` | 主歌 |
| ② 副歌循环 | `C → Dm7 → Am → Em → F6 → G7 → C` | 副歌 |
| ③ 间奏/收尾 | `Dm → Am → Em → G → G7` | 间奏、转调尾段 |

**出现频率排行：**

| 排名 | 和弦 | 说明 |
|:--:|:--:|:--|
| 🥇 | **C** | 出现最多，几乎每句都回落到 C |
| 🥈 | **F6 / F** | 主歌开头、副歌后段 |
| 🥉 | **G / G7** | 永远在 C 前面当"推进" |
| 4 | **Em** | 主歌 & 副歌都有 |
| 5 | **Am** | 副歌下行经过 |
| 6 | **Dm7 / Dm** | 副歌"谁安慰爱哭的你" |

---

## 四、一句话记住

> 主歌 = `F C Em F G C` 循环；
> 副歌 = `C Dm7 Am Em F6 G7 C` 下行；
> 结尾 = 整体升调 + `Dm Am Em G G7` 收尾。
