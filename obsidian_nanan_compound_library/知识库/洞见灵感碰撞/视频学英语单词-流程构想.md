## 核心思路
用 1–2 分钟英文视频做素材，通过「看→填→讲→用」四步学高中常见词，并结合词根词缀拓展。

## 标准流程（用户定稿版）

1. **看 3 遍**
   - 第 1 遍：不开字幕，看画面猜剧情（不求听懂）
   - 第 2 遍：看字幕，找生词
   - 第 3 遍：只听不看，确认听到

2. **文字稿挖空**
   - 先**裸听填空**，不给备选词（听力训练）
   - 填不出来再给乱序词表补填
   - 对答案，标注答案

3. **讲单词**
   - 读音、词性、语境义、视频原句
   - 顺手扩词根家族（能连就连，连不上不硬凑）

4. **原句复述**（建议新增）
   - 用视频原句角色扮演/跟读，练语感

5. **自己造句**
   - 每个词 3 句：照抄结构 / 换场景 / 自由发挥
   - 给示范答案

---

## 设计原则
- 一条视频只抓 **5–8 个目标词**，宁少不散
- 选材密度：高中高频词 **8~12 个/分钟** 最佳
- 挖空先挖整词（练听力），后续可单开一轮挖词根（练结构）
- 词根只做「能连成家族」的拓展（如 distract → tract 家族），不硬凑

## 为什么有效（理论对应）
- 看 3 遍 = 可理解输入（Input Hypothesis）
- 挖空填 = 提取练习（Retrieval Practice），记忆最强
- 讲单词+造句 = 从 receptive 到 productive
- 整条链：**听懂 → 写出 → 讲透 → 用过**（多数英语课缺最后一环）
