# ⚖️ 判断力日志

> 建立日期：2026-10-27
> 来源：《纳瓦尔宝典》——判断力从经验中来，但可以通过学习基本技能快速搭建
> 用途：把「做判断 → 等反馈 → 复盘」这个循环写下来，用别人的样本压缩自己的经验积累

---

## 为什么记这个

经验慢在两个地方：
1. **样本少**：一辈子重大决策就几十个
2. **反馈慢**：很多决策几年后才知道对错

写下来 → 循环能跑起来 → 几年压缩成几个月。

**只记判错的。** 对的不用记，因为对的没有信息量。

---

## 四句快捷键（每次判断先过一遍）

1. **谁获益？** —— 看激励结构，不看说辞
2. **机会成本是什么？** —— 我为此放弃了什么
3. **这是可逆的吗？** —— 可逆就快决，不可逆就慢决
4. **然后呢？再然后呢？** —— 二阶、三阶效应

## 常用思维模型（随时补）

| 类别 | 模型 | 一句话 |
|:--|:--|:--|
| 经济学 | 机会成本 | 真正的代价是你放弃了什么 |
| 经济学 | 边际效用递减 | 越多越不值钱 |
| 博弈论 | 重复博弈 | 长期关系里诚实划算，一次性关系相反 |
| 博弈论 | 信号 vs 空话 | 代价高的才叫信号 |
| 博弈论 | 信息不对称 | 对方为什么有动机告诉我这条 |
| 概率 | 基础概率 | 先看大基数，再看个案 |
| 概率 | 贝叶斯更新 | 新信息该改多少判断 |
| 概率 | 期望值 | 小概率大损失 vs 大概率小收益 |
| 心理学 | 激励错位 | 看谁从结果中获益 |
| 心理学 | 损失厌恶 | 人在损失面前决策会变形 |
| 心理学 | 从众 | 人多不等于对 |
| 决策 | 逆向思考 | 想避免失败，先问什么会导致失败 |
| 决策 | 可逆 vs 不可逆 | 区分开，前者快决后者慢决 |
