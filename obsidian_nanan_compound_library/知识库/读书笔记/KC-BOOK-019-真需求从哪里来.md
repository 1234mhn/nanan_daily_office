📇 卡片名称：真需求从哪里来——5个源头 + 4问验证 + 在场优势
🔖 卡片ID：KC-BOOK-019
📊 等级：L1 初铸
📅 日期：2026-10-23
📚 来源：纳瓦尔宝典「学会销售 + 学会构建」延伸思考 + 用户自身实践（韩语教学现场）

💡 核心洞察（一句话）
**没有真需求，构建得再好都白搭。而真需求不是想出来的，是"在场"看出来的、是花钱验证出来的。**

需求有三层误判：
- 以为"我觉得有用"就是需求 → 其实是自己的想象
- 以为"别人说想要"就是需求 → 口头愿望不值钱
- 以为"调研能问出需求" → 用户说不清自己痛在哪，需求藏在流程里，不在问卷里

📐 行动指南

**第一步：找需求（5个源头）**
1. **自己的痛** —— 你反复抱怨、反复绕路、反复花钱解决的事。纳瓦尔：你真正想要的，别人也想要。
2. **已经在掏钱的地方** —— 不看别人说什么，看谁已经在付钱。已成交客户 = 真需求的直接证据。
3. **反复出现的同样问题** —— 评论区"求这个"、家长群反复问的问题、搜索框联想词。真实需求会反复出现、用同样的话问出来。
4. **别人花大量时间但很笨的地方** —— 硬扛、忍受、效率极低还没解决 → 真需求（但要注意：能忍说明还不够痛）
5. **在场优势（最强）** —— 进真实场景干一段活，边干边摸。企业自己都说不清痛在哪，从外面问只会得到套话（"要提效""要AI"）。真痛往往是不起眼的地方：没人愿干的周报、系统间倒数据、没人维护的 Excel 模板。

**第二步：验需求（4问）**
1. 他**真的为这件事掏过钱**吗？（掏过=强信号；只说"挺好"=不算）
2. 他**现在怎么凑合**解决的？（正在硬扛=真需求；已忍受或已有免费替代=不够痛）
3. 他愿不愿**先付一点钱 / 给一个承诺**？（预付费、定金、报名 = 验证器；"你做出来我看看" = 嫌软弱）
4. 你**触达得到**这群人吗？（需求再真，你碰不到人，等于没需求）

**第三步：最狠的验证——别问，直接卖**
花一天做最小版本（一页介绍 + 一个样品）→ 挂价格 → 发出去。
有人付费 = 真需求；没人问 = 假需求，成本只有一天。
（与 KC-BOOK-018 同源：别在脑子里模拟，让现实给反馈。）

**第四步：把"在场"变成常态**
进入真实场景时，带着**观察者视角**，每周记一条需求观察日志：
· 哪个环节最浪费时间？
· 谁能拍板付钱？
· 他们正在为什么付钱？

🟢 绿灯（适用场景）
· 想做一个新产品/服务，但不确定有没有人要
· 已经做了很多东西却卖不出去，需要回头找需求
· 准备进入某个行业/公司，想边干边找机会
· 有自己的客户（学生、家长、同行），想从现有关系里挖需求
· 判断一个"看起来很热"的方向是不是自己能赚钱的方向

🔴 红灯（不适用场景）
· 需求已经明确、只剩执行（这时候再调研就是拖延）
· 强监管/高合规行业，不能"先卖再验证"（医疗、金融、教育资质类要先走合规）
· 面对的是你完全触达不到的客户群 —— 需求再真也别做
· 只观察一家公司就下结论 —— 一家公司的怪癖不等于市场，需要2-3家或多个部门反复出现才算
